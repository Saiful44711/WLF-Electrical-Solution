কী বদলেছে

  • Submit-এর পর নিশ্চিতকরণ: R&I Team Activity আর Technical Support-এ Submit চাপার পর সার্ভারে জমা নিশ্চিত হলে "✓ Entry submitted / Request submitted" popup আসে। সাথে Reference (support), Status আর সময় দেখায়। জমা না হলে popup আসে না, error দেখায়।
  • Auto-fill ঘর লুকানো: Name, ID আর আজকের তারিখের ঘর (যেমন Perform Date, Date) ফর্মে আর দেখায় না। সার্ভার নিজেই বসায়: তারিখ সবসময় জমার দিনের (ঢাকা)। পরে Edit করলেও আগের তারিখ থাকে। Entry দেখার সময় আর Excel-এ এগুলো আগের মতোই থাকে। এই নিয়ম R&I Team Activity-র সব ফর্ম আর Technical Support-এর সব ফর্মে।
  • Task Start / Complete Date: দেখা যায়, auto-fill হয় না, বাধ্যতামূলক না। Sales Support-এ এই দুটো ঘর নতুন যোগ হয়েছে (Task Details-এর পরে)। তারিখের বক্সের যেকোনো জায়গায় ক্লিক করলেই ক্যালেন্ডার খোলে।
  • Team Activity: "Project / Task Name" ঘর সরানো হয়েছে, শুধু Task Name আছে, বাঁ থেকে ডান পুরো চওড়া। পুরনো entry খুললে তার "Project / Task Name" আগের মতোই দেখাবে।
  • পুরো চওড়া ঘর: Task Name, Task Details (SCM-সহ), Problem Details, Solution Statement, Note ইত্যাদি বড় লেখার ঘর।
  • Other বাছলে নাম লেখার বক্স: Team Activity-র Task Category ("Others"), SCM-এর Product category, Sales-এর Support Category, Service Report-এর Damage Item Name, আর Technical Support-এর Problem Category ("Other:")-সহ যেকোনো ফর্মে যেখানে Other আছে। বক্সে নাম লেখা বাধ্যতামূলক। ডেটা একই ঘরে Other: আপনার লেখা হিসেবে জমা হয়, তাই তালিকা আর Excel-এ নামটা দেখা যায়।
  • Recent entries ছোট: প্রতিটি entry এক লাইনে: Task Name (বা মূল লেখা), নিচে কে আর কখন, পাশে Status। পুরোটা দেখতে নামে চাপুন। একসাথে অনেক বেশি entry দেখা যায়।
  • Troubleshooting বাংলা এডিট: Edit ফর্মে "বাংলা লেখা" অংশ: বিবরণ, শর্ত, সমাধান আর প্রতিটি Subcode-এর বাংলা। নিচের নিয়ম দেখুন।

১. ব্যাকআপ (বাধ্যতামূলক)

  1. Supabase প্যাকেজের backup-kit থেকে 01_STRUCTURE_BACKUP.sql আর 02_DATA_BACKUP.sql চালিয়ে দুটো CSV নিন, 03_RESTORE_TOOL.html-এ সবুজ ✓ দেখুন।

Data backup CSV-তে ইমেইল, পাসওয়ার্ডের hash আর notification key থাকে। কাউকে দেবেন না।

২. Supabase-এ ডাটাবেস আপডেট

  1. Supabase → SQL Editor → New query।
  2. UPDATE_V251.sql Notepad-এ খুলে Ctrl+A, Ctrl+C, SQL Editor-এ পেস্ট করে Run। RLS বার্তা এলে Run without RLS।
  3. ফলাফলে পাঁচটা কলামই true:
    কলামমানে
    other_name_ready"Other: নাম" সার্ভার গ্রহণ করে
    team_task_name_onlyTeam Activity-তে শুধু Task Name
    sales_dates_readySales Support-এ দুটো তারিখের ঘর
    bangla_tracking_readyপ্রতিটি বাংলা অংশ কোন ইংরেজির জন্য লেখা, তা মনে রাখা শুরু
    v251_readyনতুন সার্ভার-নিয়ম চালু
একটাই transaction, দুবার চালালেও ক্ষতি নেই। শুরুতে STOP: apply UPDATE_V250.sql এলে বুঝবেন v2.5.0-এর SQL চালানো নেই।
SQL চালানোর মুহূর্তে কেউ Team Activity বা Sales Support ফর্ম খোলা রেখে Submit করলে "Form changed. Reopen the form." আসতে পারে। ফর্ম আবার খুললেই ঠিক হবে, কোনো ডেটা নষ্ট হয় না।

৩. GitHub-এ ফাইল আপলোড

  1. WLF-GitHub-v2.5.1-UPLOAD.zip extract করে WLF-v2.5.1-upload ফোল্ডারে ঢুকুন।
  2. GitHub repo → Add file → Upload files → ফোল্ডারের ভেতরের সব কিছু (Ctrl+A) টেনে ছেড়ে দিন (১০০টির কম ফাইল)।
  3. উপরের প্রথম ঘরে Commit message: v2.5.1 Form cleanup, Other name, Bangla edit, submit confirmation → Commit changes।

ক্রম: আগে SQL (ধাপ ২), তারপর GitHub (ধাপ ৩)।

৪. লাইভ সাইটে যাচাই

  1. Ctrl+F5 বা অ্যাপ বন্ধ করে আবার খুলুন। ⋮ মেনুর নিচে WLF v2.5.1।
  2. R&I Team Activity → Team Activity: Name, ID, Perform Date দেখাবে না; Task Name পুরো চওড়া। Task Category-তে Others টিক দিলে বক্স আসবে। Submit-এর পর ✓ popup।
  3. Sales Support: Task Start Date আর Task Complete Date আছে, ক্লিক করলে ক্যালেন্ডার।
  4. Technical Support → + New request: Name/ID/Date দেখাবে না; Problem Category-তে "Other:" বাছলে বক্স; Submit-এর পর Reference-সহ popup।
  5. Troubleshooting: Super Admin একটা কোড খুলে Edit → "বাংলা লেখা" অংশ দেখবেন।

বাংলা এডিটের নিয়ম (Troubleshooting)

  • ইংরেজি আর বাংলা দুটোই বদলালেন: বাংলা ভিউতে নতুন বাংলা দেখাবে।
  • শুধু ইংরেজি বদলালেন (যেমন নতুন solution যোগ): বাংলা ভিউতে ওই অংশ ইংরেজিতে দেখাবে, উপরে হলুদ লেখা "বাংলা হালনাগাদ হয়নি"। Edit ফর্মেও ওই বাংলা ঘরের পাশে "⚠ পুরনো" দেখাবে। বাংলা ঠিক করে Save করলেই আবার বাংলা দেখাবে।
  • ইংরেজি বদলেছেন কিন্তু বাংলা ঠিকই আছে (যেমন শুধু বানান ঠিক করলেন): "বাংলা মিলিয়ে দেখেছি" টিক দিয়ে Save করুন, সব বাংলা অংশ হালনাগাদ ধরা হবে।
  • যে অংশ শুধু বাংলায় বদলায় না বা অন্য অংশ ছুঁয়ে দেখেননি, সেগুলো আগের মতো থাকে। একটা অংশ পুরনো হলে বাকিগুলো বাংলাতেই দেখায়।
  • যন্ত্র দিয়ে নিজে থেকে অনুবাদ হয় না। বাংলা লেখা Super Admin হাতে লিখবেন।
