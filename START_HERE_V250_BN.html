কী বদলেছে

  • User Management → Copy access from: একজন ইউজারের সব টিক আরেকজনের ফর্মে কপি করা যায়। ইউজার বাছাই করে Copy ticks চাপুন, তারপর Save user & access। Save না চাপলে কিছু বদলায় না।
  • Duplicate ID: দুজনের একই ID থাকলে দুজনের নামের পাশে লাল Duplicate ID চিহ্ন, বাক্সের চারপাশে লাল দাগ, আর ভেতরে কার সাথে মিলছে সেটা লেখা থাকে। উপরে মোট সংখ্যাও দেখায়।
  • Change history: Super Admin কারো Name, ID, Section, User type (Super Admin / R&I / User), Status বা option বদলালে কে, কখন, কী থেকে কী করেছে তা জমা হয়। ইউজারের বাক্সে Change history চাপলে দেখা যায়। শুধু Super Admin দেখতে পারে। ইতিহাস v2.5.0 থেকে শুরু, আগের পরিবর্তন নেই।
  • Push notification: নতুন access request এলে সব Super Admin-এর ফোন/কম্পিউটারে, আর কোনো support request কারো কাছে Forward হলে সেই R&I ইউজারের কাছে নোটিফিকেশন যায়। প্রত্যেকে নিজের ডিভাইসে My Profile → Notifications → Turn on notifications দিয়ে চালু করবেন। নোটিফিকেশনে চাপলে অ্যাপের ঠিক পাতাটা (User Management বা Technical Support) খোলে।
  • পুরনো request-এর রং: Technical Support-এ যে request এখনো Solved হয়নি, সেটা ২ দিন পর হলুদ আর ৩ দিন পর লাল হয়, সাথে "4 days old" লেখা। Super Admin Change days চেপে দিন বদলাতে পারেন।
  • Troubleshooting বাংলায়: উপরে English / বাংলা বোতাম। আপনার দেওয়া দুটো বাংলা ম্যানুয়াল (MOT ও NICE3000+) থেকে ১৬৬টি কোডের বাংলা যোগ হয়েছে। বাংলায় খোঁজাও যায়। কোনো অংশের বাংলা না থাকলে সেটা ইংরেজিতে দেখায় আর উপরে জানিয়ে দেয়। বেছে নেওয়া ভাষা ডিভাইসে মনে থাকে।
  • Cancelled: R&I Team Activity-র সব ফর্মে, আগের সব entry-তে আর নতুন category-র শুরুর ফর্মে বানান এখন "Cancelled"।
  • R&I Team Activity-র নতুন চেহারা: সব category (Team, SCM, Sales, Reports) এখন একটা ড্রপডাউনে, ভাগ করে সাজানো। বড় স্ক্রিনে ফর্ম বাঁদিকে আর Recent entries ডানদিকে। ফোনে আগের মতো উপরে-নিচে।
  • দ্রুত গতি (কোনো ফিচার বন্ধ না করে): লগইনের পরের তিনটা সার্ভার কল এখন একসাথে যায়, একটার পর একটা নয়। Excel/PowerPoint-এর বড় ফাইলটা (প্রায় ৩৮০ KB) শুধু ডাউনলোডের সময় লোড হয়। অ্যাপের ফাইলগুলো ছোট (minify) করা হয়েছে। পরীক্ষায় প্রতি সার্ভার কলে ১৫০ ms দেরি ধরে: অ্যাপ আবার খোলা ১১৩৮ → প্রায় ৮৫৫ ms (প্রায় ২৫% দ্রুত), লগইন ১২৩৫ → প্রায় ১০৭০ ms, প্রথমবার ডাউনলোড হওয়া JavaScript ১৮৫২ → ১০৭৬ KB। অফলাইনেও Excel ডাউনলোড কাজ করে (ফাইলটা আগেই ক্যাশে থাকে)।

  2. 03_RESTORE_TOOL.html-এ দুটো CSV দিয়ে দুবারই সবুজ "✓ ব্যাকআপ সম্পূর্ণ" দেখুন।

২. Supabase-এ ডাটাবেস আপডেট

  1. Supabase → আপনার প্রজেক্ট → SQL Editor → New query।
  2. UPDATE_V250.sql Notepad-এ খুলে Ctrl+A, Ctrl+C করুন, SQL Editor-এ পেস্ট করে Run চাপুন। ফাইলটা বড় (প্রায় ২০০ KB, বাংলা লেখার জন্য), পেস্ট হতে কয়েক সেকেন্ড লাগতে পারে।
  3. "Potential issue detected / RLS" বার্তা এলে Run without RLS চাপুন। নতুন সব টেবিলের RLS এই SQL নিজেই চালু করে।
  4. ফলাফলে এই কলামগুলো দেখুন:
    কলামযা হওয়া উচিতমানে
    change_history_readytrueপরিবর্তনের ইতিহাস রাখার টেবিল তৈরি
    push_readytrueNotification-এর টেবিল আর নতুন access request-এর trigger তৈরি
    support_colours_readytrueহলুদ/লালের দিন (২ ও ৩) সেট হয়েছে
    cancelled_spelling_fixedtrue"Canceled" আর কোথাও নেই
    bangla_entries166এতগুলো কোডে বাংলা যোগ হয়েছে
    v250_rules_readytrueনতুন সার্ভার-নিয়ম চালু
পুরো SQL একটাই transaction। error হলে কিছুই বদলায় না। দুবার চালালেও ক্ষতি নেই। শুরুতে STOP: apply UPDATE_V240.sql এলে বুঝবেন v2.4.x-এর SQL চালানো নেই।

৩. নতুন Edge Function: wlf-push (Notification পাঠানোর জন্য)

এটা ছাড়া অ্যাপের বাকি সব কাজ করবে, শুধু Notification যাবে না। কোনো key বা secret হাতে লিখতে হবে না: function প্রথমবার চলার সময় নিজেই key বানিয়ে ডাটাবেসে রাখে।

  1. Supabase → বাঁদিকে Edge Functions → Deploy a new function → Via Editor।
  2. Function name ঠিক এভাবে দিন: wlf-push
  3. Editor-এর পুরনো কোড মুছে Supabase প্যাকেজের edge-function/wlf-push/index.ts ফাইলের পুরো কোড পেস্ট করুন → Deploy function।
  4. Deploy হলে function-এর পাতায় Details (বা Settings) → Verify JWT / "Enforce JWT verification" বন্ধ (OFF) করে Save করুন। wlf-admin-এর মতোই। এটা নিরাপদ, কারণ function শুধু ডাটাবেস যা আগে থেকে সারিতে রেখেছে সেটাই পাঠায়, বাইরের কেউ ডেকে অন্য কিছু পাঠাতে পারে না।
  5. পরীক্ষা: function পাতার Test (বা Invoke) থেকে Method POST, body {} দিয়ে চালান। উত্তরে "ok":true আর একটা লম্বা publicKey এলে ঠিক আছে।
Verify JWT চালু থাকলে ফোনে নোটিফিকেশন চালুর সময় বা request পাঠানোর পর function "401" দেবে আর নোটিফিকেশন যাবে না। তখন ধাপ ৪ আবার দেখুন।

৪. GitHub-এ ফাইল আপলোড

  1. WLF-GitHub-v2.5.0-UPLOAD.zip extract করুন, ভেতরের WLF-v2.5.0-upload ফোল্ডারে ঢুকুন।
  2. GitHub-এ repo খুলে Add file → Upload files।
  3. ফোল্ডারের ভেতরের সব কিছু (Ctrl+A) টেনে আপলোড পেজে ছেড়ে দিন। ১০০টির কম ফাইল, তাই একবারেই হবে।
  4. উপরের প্রথম ঘরে (Commit message) লিখুন: v2.5.0 Notifications, change history, Bangla troubleshooting, speed। নিচের বড় description ঘরটা খালি রাখলেও চলে। তারপর Commit directly to the main branch → Commit changes।
  5. Actions ট্যাবে সবুজ ✓ পর্যন্ত অপেক্ষা করুন (২–১৫ মিনিট)।
ক্রম: ধাপ ২ (SQL) → ধাপ ৩ (Edge Function) → ধাপ ৪ (GitHub)। SQL-এর আগে নতুন সাইট চালু হলে নতুন বোতামগুলো "Unsupported action" দেখাবে, তবে কোনো ডেটা নষ্ট হবে না।

৫. লাইভ সাইটে যাচাই

  1. Ctrl+F5 চাপুন, বা অ্যাপ বন্ধ করে আবার খুলুন (দরকার হলে "Update" বোতাম)। ⋮ মেনুর নিচে WLF v2.5.0 দেখাবে।
  2. User Management: কোনো ইউজার খুলুন → Copy access from → একজন বাছুন → Copy ticks → Save user & access → Change history-এ আজকের পরিবর্তন দেখাবে।
  3. Technical Support → একটা টিম: উপরে "Not Solved for 2+ days / 3+ days" লেখা থাকবে। পুরনো request থাকলে হলুদ/লাল দেখাবে।
  4. Troubleshooting → NICE3000+ → Error Solution → Err20 → উপরে বাংলা চাপুন।
  5. R&I Team Activity: উপরের ড্রপডাউন থেকে ফর্ম বাছুন। কম্পিউটারে ফর্ম আর Recent entries পাশাপাশি দেখাবে।
  6. Notification: নিচের অংশ দেখুন।

Notification চালু করা (প্রত্যেক ইউজার নিজের ডিভাইসে)

  1. Android / কম্পিউটার (Chrome, Edge): অ্যাপে লগইন → My Profile → Notifications → Turn on notifications → ব্রাউজার জিজ্ঞেস করলে Allow। "On for this device" দেখাবে।
  2. iPhone / iPad (iOS 16.4 বা নতুন): আগে Safari-তে সাইট খুলে Share → Add to Home Screen। তারপর Home Screen-এর WLF আইকন থেকে অ্যাপ খুলে উপরের মতো চালু করুন। Safari-র সাধারণ ট্যাব থেকে iPhone-এ নোটিফিকেশন চালু হয় না।
  3. পরীক্ষা: Super Admin নিজের ফোনে চালু করুন। তারপর অন্য কাউকে দিয়ে (বা একটা টেস্ট ইমেইল দিয়ে) নতুন account request পাঠান। কয়েক সেকেন্ডে "New access request" নোটিফিকেশন আসা উচিত।
  4. Forward-এর পরীক্ষা: R&I ইউজার নিজের ফোনে চালু করবেন, তারপর অন্য কেউ তার কাছে একটা request Forward করবেন।
  5. "Blocked in settings" দেখালে: ফোন/ব্রাউজারের সেটিংসে এই সাইটের Notifications Allow করুন, তারপর আবার চেষ্টা করুন।
একই ডিভাইসে অন্য কেউ লগইন করলে নোটিফিকেশন নিজে থেকেই নতুন লগইন করা জনের নামে চলে যায়। শেয়ার করা কম্পিউটারে লগআউটের আগে Turn off চাপুন, নইলে লগআউটের পরও সেই ডিভাইসে আগের জনের নোটিফিকেশন আসতে পারে।

  • বাংলা ম্যানুয়ালে নেই: MOT Er88 আর NICE3000+ Err45-এর subcode 107। এগুলো ইংরেজিতেই দেখাবে। বাংলা ম্যানুয়ালে Err94 আছে, কিন্তু অ্যাপে এই কোড নেই, তাই যোগ হয়নি।
  • বাংলা লেখা এডিট: Super Admin অ্যাপে Edit করলে এখন শুধু ইংরেজি অংশ বদলায়। বাংলা অংশ যেমন আছে তেমনই থাকে, মুছে যায় না। বাংলা এডিট করার ব্যবস্থা পরের আপডেটে করা যায়।
  • Notification কখন যায়: নতুন request বা Forward-এর সাথে সাথেই অ্যাপ wlf-push ডাকে, তাই সাধারণত কয়েক সেকেন্ডেই যায়। সেই মুহূর্তে নেট না থাকলে পরে কেউ অ্যাপ খুললেই পাঠানো হয় (৩ দিন পর্যন্ত, সর্বোচ্চ ৫ বার চেষ্টা)।
  • খরচ: এটা Web Push, তাই প্রতি নোটিফিকেশনে কোনো খরচ নেই। Supabase-এর ফ্রি প্ল্যানে মাসে ৫ লাখ Edge Function কল, এই অ্যাপের ব্যবহারে এর অনেক নিচে থাকবে।
