  • পুরোনো ব্যাকআপ history ডিলিট: Excel backup history ও Support data backup history, দুটোতেই প্রতি সারিতে Delete এবং Delete all history (DELETE লিখে নিশ্চিত করতে হয়)। শুধু তালিকার এন্ট্রি মোছে; Google Drive-এর ফাইল কখনো মোছে না।

  • Documents Links: User Management-এ নতুন অপশন Documents Links / Open documents। Super Admin যাকে টিক দেবেন সে-ই Documents Links খুলতে পারবে। এখন যারা খুলতে পারত তারা SQL-এর পর নিজে থেকেই অনুমতি পাবে (কারো কিছু বন্ধ হবে না); নতুন ইউজারে ডিফল্ট টিক নেই, আপনি দেবেন। Add / Edit / Delete (ডকুমেন্ট, ফোল্ডার, সাব মেনু) শুধু Super Admin — এটা ডাটাবেসেও আটকানো।
  • আগেই করা ছিল (নতুন কাজ নেই): Request access-এর বাধ্যতামূলক ঘর (v2.5.7), ৭ দিনের পুরোনো wlf_usage স্বয়ংক্রিয় মোছা (v2.5.7), MOTCUBE drive error ও history-র সুন্দর নাম (v2.5.8)।

৩. Edge Function wlf-maintenance আবার deploy (একটাই ফাইল)

নতুন মডিউলগুলোর জন্য Google Drive-এ সেভ করার কোড এই ফাংশনে থাকে, তাই এটা বদলাতে হবে। Google-এর তিনটা secret আগের মতোই থাকবে; নতুন করে কিছু দিতে হবে না। ফাংশনের কোড এবার একটাই ফাইলে দেওয়া আছে: প্যাকেজের edge-function/wlf-maintenance/index.ts।

  1. Supabase ড্যাশবোর্ডে আপনার প্রজেক্ট খুলুন → বাঁ মেনুতে Edge Functions।
  2. তালিকা থেকে wlf-maintenance-এ ক্লিক করুন।
  3. উপরের ট্যাবগুলো থেকে Code (কোনো সংস্করণে Editor) খুলুন। বাঁ পাশে ফাইলের তালিকায় index.ts আছে; তার ওপর ক্লিক করে খুলুন।
  4. ডান পাশের কোড বক্সে ক্লিক করে Ctrl+A (সব নির্বাচন), তারপর Delete।
  5. কম্পিউটারে প্যাকেজের edge-function/wlf-maintenance/index.ts ফাইলটা Notepad (বা যেকোনো টেক্সট এডিটর) দিয়ে খুলুন → Ctrl+A, Ctrl+C।
  6. Supabase-এর কোড বক্সে Ctrl+V দিয়ে পেস্ট করুন। (প্রথম লাইন // @ts-nocheck। লাল দাগ/সতর্কতা দেখালে চিন্তা নেই: এই লাইন থাকলে টাইপ-চেক বন্ধ।)
  7. ডান-নিচে বা উপরে Deploy updates (কখনো শুধু Deploy) বাটনে ক্লিক করুন। "Successfully deployed" বার্তা আসা পর্যন্ত অপেক্ষা করুন।
  8. Details (বা Settings) ট্যাব খুলে দেখুন Verify JWT (বা "Verify JWT with legacy secret") বন্ধ (OFF) আছে। না থাকলে বন্ধ করে Save changes। (wlf-push-এর সাথে যেভাবে আছে সেভাবেই।)
  9. বাঁ পাশে আগে থেকে আরও ফাইল (যেমন _shared/...) থাকলে সেগুলো মুছতে হবে না; নতুন index.ts সেগুলো ব্যবহার করে না।
ক্রম: SQL আগে, Edge Function পরে। উল্টো হলে নতুন বাটনে "Choose a valid module…" ধরনের error আসবে; SQL চালালেই ঠিক। wlf-admin ও wlf-push বদলাতে হবে না।

৫. যাচাই

  1. Ctrl+F5 / অ্যাপ রিলোড; ⋮ মেনুর নিচে WLF v2.6.2।
  2. Super Admin → Storage & Backup → Excel backup: ছয়টা বাটন আছে কি দেখুন। "Backup without Clear" রেখে R&I Project চাপুন: Excel নামবে, নিচের status-এ "A verified copy was saved to Google Drive", Drive-এর WLF Backups ফোল্ডারে ফাইল।
  3. History-তে ওই সারির Delete চেপে মুছে দেখুন (Drive-এর ফাইল থাকবে)।
  4. কোনো পরীক্ষামূলক লিফট QMS Data থেকে Delete → Recycle Bin-এ "QMS lift record" → Restore।
  5. User Management → কোনো ইউজার খুলুন: Documents Links / Open documents টিক দেখা যাবে; বন্ধ করে ওই ইউজারে লগইন করলে Documents Links মেনু থাকবে না।
  6. Clear আসল ডেটায় চালানোর আগে অবশ্যই একবার "without Clear" চালিয়ে Excel খুলে মিলিয়ে নিন।
