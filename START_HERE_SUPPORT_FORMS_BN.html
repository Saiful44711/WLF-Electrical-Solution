এরপর GitHub source update দিন

Supabase package-এর SQL update সফল হওয়ার পর এই ধাপ করুন।

১. Extract করা সব file ও folder নিন

  1. WLF-Support-Forms-GitHub-Update.zip-এ right-click → Extract All করুন।
  2. Extract হওয়া folder-এর ভেতরে ঢুকুন। একই জায়গায় data, scripts, supabase, tests folder এবং package.json, README.md পাবেন।
  3. ওই জায়গায় Ctrl+A দিয়ে সব file ও folder select করুন।

২. বর্তমান repository-এর মূল পাতায় আপলোড করুন

  1. আপনার repository খুলুন
  2. Branch main রেখে প্রথম পাতায় Add file → Upload files চাপুন।
  3. কম্পিউটারে select করা সব file ও folder GitHub upload area-তে একসঙ্গে drag করুন।
  4. Upload list-এ tests/support-forms-workbook.test.cjs, tests/supabase-e2e.cjs, data/technical-support-forms-20261107.json এবং supabase/UPDATE_SUPPORT_FORMS_20261107.sql আছে মিলিয়ে নিন। Path-এর শুরুতে ZIP-এর বাইরের folder-এর নাম থাকলে extracted folder-এর ভেতরের items দিয়ে আবার upload করুন।
  5. Commit message লিখুন Update Technical Support fields from Excel। Commit directly to the main branch → Commit changes চাপুন।

৩. নতুন Actions run দেখুন

Actions-এ নতুন commit-এর Deploy WLF PWA to GitHub Pages খুলুন। build ও deploy দুটো সফল ও সবুজ হতে হবে। মূল পরীক্ষায় ৫৬টি test এবং browser test-এ ছয়টি নতুন form যাচাই হবে।

লাইভ form definition বসবে Supabase package-এর SQL চালালে। এই GitHub upload নতুন definition, migration এবং পরীক্ষাগুলো repository-তে রাখে।
