ক্রম অনুযায়ী কাজ

ক্রম: SQL আগে → Edge Function → GitHub → Turn on। v2.6.4 থেকে v2.6.8-এর SQL বসানো না থাকলে আগে সেগুলো ক্রমানুসারে বসান। v2.6.9-এর কোনো SQL ছিল না।

১. SQL (Supabase)

  1. supabase.com → আপনার project → বাম পাশে SQL Editor → New query।
  2. WLF-Supabase-v2.7.0.zip খুলে UPDATE_V270.sql Notepad-এ খুলুন → Ctrl+A, Ctrl+C → Supabase-এর বক্সে Ctrl+V → Run।
  3. নিচে ফল দেখাবে v270_ready = true। (দুবার চালালেও ক্ষতি নেই।)

২. Extension দুটো চালু আছে কিনা দেখা

  1. বাম পাশে Database → Extensions।
  2. সার্চ বক্সে pg_cron লিখুন। সুইচ সবুজ (ON) থাকলে ঠিক আছে। বন্ধ থাকলে সুইচে চাপুন → Enable extension।
  3. একইভাবে pg_net চালু করুন।
  4. এই ধাপে কোনোটা চালু করতে হলে ১ নম্বর ধাপের SQL আরেকবার চালান।

৩. Edge Function বদলানো

  1. বাম পাশে Edge Functions → wlf-maintenance → Code ট্যাব।
  2. কোডের বক্সে ক্লিক করে Ctrl+A, তারপর Delete।
  3. প্যাকেজের edge-function/wlf-maintenance/index.ts Notepad-এ খুলুন → Ctrl+A, Ctrl+C → Supabase-এর বক্সে Ctrl+V। (প্রথম লাইন // @ts-nocheck। লাল দাগ দেখালে চিন্তা নেই।)
  4. Deploy updates চাপুন এবং "Successfully deployed" আসা পর্যন্ত অপেক্ষা করুন।
  5. Details ট্যাবে Verify JWT বন্ধ (OFF) থাকতে হবে। এটা জরুরি, নইলে রাতের সময়সূচি কাজ করবে না।

৪. GitHub আপলোড

  1. WLF-GitHub-v2.7.0-UPLOAD.zip extract করুন।
  2. GitHub-এ repo খুলুন → Add file → Upload files → extract করা ফোল্ডারের ভেতরের সব ফাইল ও ফোল্ডার টেনে ছাড়ুন → নিচে Commit changes।
  3. Actions ট্যাবে সবুজ টিক আসা পর্যন্ত অপেক্ষা করুন। তারপর সাইটে Ctrl+F5 চাপুন। Account পাতায় build 2.7.0 দেখাবে।

৫. অ্যাপে চালু করা (Super Admin)

  1. Storage & Backup → নিচে নামলে Monthly reports কার্ড পাবেন।
  2. Turn on চাপুন। লেখা আসবে "On. Every night at 02:00 …"।
  3. পরীক্ষা করতে Month-এ October 2026 বা November 2026 বেছে Make report now চাপুন। কয়েক সেকেন্ড পরে "Saved in Google Drive: …" আসবে, আর নিচের তালিকায় ফাইলের লিংক দেখাবে।
  4. Google Drive-এ তিনটা নতুন ফোল্ডার দেখবেন: Technical Support Monthly Report, R&I Team Activity Monthly Report, Damage Demand Monthly Report।

জানা দরকার

  • Section কীভাবে ধরা হয়: request যে team form দিয়ে পাঠানো হয়েছে (Commissioning, After Sales ইত্যাদি), সেটাই তার section। যে section-এর কোনো request নেই, তার শিটেও লেখা থাকে "No records in this month."
  • Repeat problem: মাসে যে সমস্যা সবচেয়ে বেশিবার এসেছে, সেটা হলুদ রঙে চিহ্নিত থাকে। একই Lift ID-তে একই সমস্যা দুই বা তার বেশিবার এলে আলাদা টেবিলে দেখায়। দুটো সমস্যা সমান সংখ্যায় এলে কোনোটাই হলুদ হয় না, যাতে ভুল বার্তা না যায়।
  • মাসের হিসাব ঢাকা সময়ে: যেমন ১ নভেম্বর রাত ১২:১০-এর request নভেম্বরের হিসাবে যায়।
  • Backup with Clear-এর আগে রিপোর্ট: Excel backup-এর "Backup with Clear" দিয়ে মুছে ফেলা record পরে কোনো রিপোর্টে আসবে না। তাই কোনো মাস Clear করার আগে সেই মাসের রিপোর্ট বানিয়ে রাখুন। ১ তারিখের নিজে থেকে বানানো রিপোর্টেই এটা হয়ে যায়।
  • রিপোর্ট বানানো ও দেখা শুধু Super Admin পারেন (Storage & Backup পাতার মতোই)। Drive-এর ফোল্ডার আপনি চাইলে অন্যদের সঙ্গে শেয়ার করতে পারেন।
  • Drive থেকে কোনো ফাইল আপনি নিজে মুছে ফেললে সেই মাস আবার "Make report now" দিয়ে বানানো যায়। তালিকা থেকে "Delete from list" চাপলে Drive-এর ফাইল থেকেই যায়।

যা এখানে যাচাই করা যায়নি

  • আসল pg_cron আর pg_net দিয়ে রাতের সময়সূচি। আমার পরীক্ষার ডাটাবেসে এই দুটো extension নেই। "চালু নেই" অবস্থায় সঠিক বার্তা আসে কিনা দেখা হয়েছে, আর সার্ভারের রিপোর্ট-বানানোর পুরো ধাপ নকল Drive দিয়ে চালানো হয়েছে। প্রথম রাতের পরে কার্ডের "Last check" দেখে নিশ্চিত হবেন।
  • আসল Google Drive-এ ফাইল ও ফোল্ডার তৈরি। একই ধরনের Drive ব্যবস্থা আগের backup-গুলোতে কাজ করছে, কিন্তু নতুন ফোল্ডারগুলো এখান থেকে দেখা যায়নি।
  • Supabase-এ Edge Function deploy। কোডের syntax পরীক্ষা হয়েছে, কিন্তু Deno-তে চালানো যায়নি।
  • Microsoft Excel-এ খোলা। ফাইলগুলো LibreOffice-এ খুলে প্রিন্ট-ভিউ দেখা হয়েছে। Excel-এ রং বা কলামের চওড়া সামান্য আলাদা দেখাতে পারে।
