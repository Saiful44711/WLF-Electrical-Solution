QMS-এ AVR, AVR/Battery serial, Serial permission ও QMS Excel: deployment নির্দেশিকা

AVR model এখন Control system অংশে; নিজস্ব input/output table; serial numbers table-এর আলাদা access; QMS Data-র Excel এখন backup-এর একই format-এ।

কী বদলেছে (v2.6.7)

  • AVR model: "3 · Control system and serial numbers" অংশে। Motor বাছলে suggested AVR model নিজে নিজে বসে; চাইলে হাতে বদলানো যায়। AVR item dropdown নেই। যে model-ই বাছুন, তার সব item input-এ আলাদা table-এ দেখায় এবং save হয়।
  • Output: নতুন "6 · AVR" table, "Other components"-এর আগে। তাই table নম্বর এখন ১–৯: Other components = ৭, Paid feature = ৮, Special note = ৯।
  • Serial number: নতুন AVR SL (AVR model বাছলে বাধ্যতামূলক) ও Battery SL (ঐচ্ছিক, বড় ঘর, সর্বোচ্চ ২০০ অক্ষর; ৫টা battery কমা দিয়ে)। Output-এর "4 · Serial numbers" ও Excel-এ আছে।
  • বাধ্যতামূলক: Address, Motor type, Lift type (আগে Gearless/Passenger আগে থেকে বসানো ছিল, এখন "Select…")। Server-ও যাচাই করে।
  • Serial numbers table access: User Management-এ নতুন option "QMS / See and download the Serial numbers table"। যার নেই সে স্ক্রিনে বা কোনো Excel-এ serial দেখে না। Super Admin সবসময় দেখে।
  • QMS Data: নতুন Recorded from / to ফিল্টার (lift record যেদিন তৈরি)। "Download Excel (these results)" এখন Excel backup-এর একই workbook দেয়: QMS Lifts (নতুন AVR model কলামসহ), QMS Components, QMS Serial numbers, QMS Output Tables। এক lift খুলে Download Excel আগের মতোই এক শিটের রিপোর্ট।
  • Hardware Catalogue: আপনার "AVR Specification" শিট থেকে AVR 15, 20, 30, 40, 60, 100 KVA (প্রতিটিতে ১৫ সারি)। শিটে যে model নেই (যেমন 80 KVA) সেগুলো ফাঁকা।
  • সব Excel ও backup: নতুন তথ্য (AVR table, AVR/Battery serial, AVR model কলাম) এক জায়গা থেকে তৈরি হয়, তাই lift Excel, QMS Data Excel, Excel backup ও Drive backup সবখানে একই। JSON backup/restore ও পূর্ণ backup-এও নতুন serial যায়।

গুরুত্বপূর্ণ: Serial permission

V267 চালানোর পর Super Admin ছাড়া কেউ Serial numbers table দেখবে না, যতক্ষণ না আপনি User Management-এ প্রতিজন user-কে "QMS / See and download the Serial numbers table" দেন। এখন যারা দেখতে পায় তারাও হারাবে। এটা ইচ্ছাকৃত, কারণ "কে পাবে, কে পাবে না" আপনি ঠিক করবেন।

আমি যা ধরে নিয়েছি

বিষয়অনুমান
AVR SL বাধ্যতামূলক?শুধু যখন AVR model বাছা আছে। AVR না থাকলে ফাঁকা থাকতে পারে। Battery SL সবসময় ঐচ্ছিক।
Battery ঘরের সীমাআপনি "১০০ digit" বলেছেন; কমা/স্পেস ধরে ২০০ অক্ষর দিয়েছি।
AVR কখন auto বসেপ্রতিবার motor বাছলে/বদলালে। তার পরে হাতে বদলালে সেটাই থাকে (পরের motor বদল পর্যন্ত)। Catalogue-এ ওই size না থাকলে auto বসে না।
AVR শিটের Item code/Brand/Supplier/Priceশিটে শুধু প্রথম সারি ("Full AVR")-তে আছে; বাকি সারি ফাঁকা, output-এ "no code"।
Hardware Name / SpecificationHardware Name → Hardware, Specification → Spec, Category → Group। শিটে Item name নেই, তাই ফাঁকা।
QMS Data ফিল্টারের তারিখlift record তৈরির দিন (ঢাকা সময়), Excel backup-এর period যে তারিখে চলে তাই।
QMS Data download-এর সীমা৫০টা করে পাতায় এনে সর্বোচ্চ ২০০০ lift; বেশি হলে তারিখ ছোট করতে বলে।
Serial না-দেখা user lift edit করলেঘর ফাঁকা রাখলে আগের serial থেকে যায়; নতুন লিখলে শুধু সেই ঘর বদলায়। নতুন lift বানালে সব serial নিজে লিখতে হয়।
পুরোনো lift-এ Address/Motor type/Lift type ফাঁকা থাকলেEdit করে Save করতে হলে ওগুলো ভরতে হবে।
পুরোনো lift-এর AVRআগে একটা item সংরক্ষিত ছিল; সেটাই "6 · AVR"-এ দেখায়। নতুন করে সব item চাইলে Edit → Save।

১. Supabase SQL (একটাই)

  1. Supabase → SQL Editor → New query।
  2. UPDATE_V267.sql খুলে Ctrl+A, Ctrl+C; Editor-এ পেস্ট; Run। RLS বার্তা এলে Run without RLS।
  3. ফলাফলে serials_permission_ready = true, avr_15_rows = 15, avr_models_with_data = 6, v267_ready = true থাকা উচিত।
V266 না চালিয়ে V267 চালালে "Run UPDATE_V266.sql first" আসবে। V264, V265, V266 এখনও না চালালে ক্রমে চালান। দুবার চালালেও AVR সারি দ্বিগুণ হয় না।

২. Edge Function wlf-maintenance আবার deploy

  1. Supabase → Edge Functions → wlf-maintenance → Code; index.ts নির্বাচিত।
  2. কোড বক্সে ক্লিক করে Ctrl+A, Delete।
  3. প্যাকেজের edge-function/wlf-maintenance/index.ts Notepad-এ খুলে Ctrl+A, Ctrl+C; বক্সে Ctrl+V।
  4. Deploy updates; "Successfully deployed" পর্যন্ত অপেক্ষা। Verify JWT OFF থাকতে হবে।
ক্রম: SQL আগে, Edge Function পরে, সবশেষে GitHub।

৪. যাচাই

  1. Ctrl+Shift+R; ⋮ মেনুর নিচে WLF v2.6.7।
  2. User Management-এ একজন user খুলে "QMS / See and download the Serial numbers table" দিন বা বাদ রাখুন।
  3. QMS Input: Address/Motor type/Lift type খালি থাকলে Save হয় না; motor বাছুন → AVR model নিজে বসে; "3 · Control system"-এর নিচে AVR-এর সব item; AVR SL ও বড় Battery SL ঘর।
  4. Save করে QMS Data-য় খুলুন: "6 · AVR" table, serial table-এ AVR ও Battery; Download Excel।
