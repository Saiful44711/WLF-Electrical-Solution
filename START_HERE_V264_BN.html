কী বদলেছে (v2.6.4)

  • Admin Panel: মেনুর "Dashboard" এখন Admin Panel। চওড়া লেআউট ও Full screen বাটন। উপরে প্রতিটি অনুমোদিত R&I ইউজারের আলাদা কার্ড: sector অনুযায়ী Completed / Ongoing / Incomplete ও ব্যয়িত সময় (Team Activity, SCM & Supplier communication, Sales Support, Reports), Technical Support (Received / Solved / Not solved / Forwarded), Damage Demand ও Supplier Claim উত্থাপনের সংখ্যা, এবং ১২ মাসের performance curve। নিচে আগের মতো মেনু-ভিত্তিক কার্ডগুলো।
  • Technical Support কার্ড থেকে "Who handled them" টেবিল সরানো হয়েছে (ওই তথ্য এখন প্রতি ইউজারের কার্ডে)।
  • কে Admin Panel দেখবে: Super Admin ঠিক করবেন, User Management → ইউজার → Permissions → "Admin Panel / View team performance and export" টিক দিয়ে। (আগের Dashboard-এর টিকই, শুধু নাম বদলেছে; আগে যাদের ছিল তাদের থাকবে।)
  • Storage & Backup-এ একটাই "Backup" কার্ড: উপরে কাজের ডেটা (Technical Support, R&I Team Activity, R&I Project Manager, QMS data, Damage Demand, Supplier Claim) period ও Clear সহ; একই কার্ডের নিচে "Settings and reference data" (Hardware Catalogue, Components Data, Documents Links, settings, ফর্ম, categories, Troubleshooting, announcements, ইউজার তথ্য) শুধু backup, Clear কখনো এগুলো ছোঁয় না। পুরোনো Technical Support ফাইল-ব্যাকআপ ভাঁজ-করা অংশে রাখা আছে।
  • QMS Data → Download Excel (একটা লিফট): এখন একটাই শিট, A4 landscape প্রিন্টের উপযোগী, স্ক্রিনের ক্রমে ৬টা table, নিচে "Design & Developed by Md. Saiful Islam" ও পাতা নম্বর। (আগের ৩ শিটের ফাইল আর হয় না।)
  • QMS data-র Excel backup ও "Download Excel (these results)": নতুন শিট QMS Output Tables: প্রতি table-সারি এক সারিতে, শুরুতে Lift ID, Project, Address, Delivery date, Controller, Table no., Table name। অনেক প্রজেক্ট একসাথে ডাউনলোড করলেও এক শিটে থাকে; Filter/Pivot চলবে। আগের ৩ শিট (QMS Lifts, Components, Serial numbers) থাকছে।

১. Supabase SQL (একটাই)

  1. Supabase → SQL Editor → New query।
  2. প্যাকেজের UPDATE_V264.sql খুলে Ctrl+A, Ctrl+C; Editor-এ পেস্ট; Run। RLS বার্তা এলে Run without RLS।
  3. ফলাফলে admin_panel_ready = true, permission_label = Admin Panel / View team performance and export, v264_ready = true থাকা উচিত।
V263 না চালিয়ে V264 চালালে "Run UPDATE_V263.sql first" আসবে ও কিছু বদলাবে না। দুবার চালালেও সমস্যা নেই।

২. Edge Function wlf-maintenance আবার deploy (একটাই ফাইল)

QMS Output Tables শিট এই ফাংশনে তৈরি হয়। Google-এর secret বদলাতে হবে না।

  1. Supabase ড্যাশবোর্ড → Edge Functions → wlf-maintenance → Code ট্যাব; index.ts নির্বাচিত।
  2. কোড বক্সে ক্লিক করে Ctrl+A, Delete।
  3. প্যাকেজের edge-function/wlf-maintenance/index.ts Notepad-এ খুলে Ctrl+A, Ctrl+C; Supabase-এর বক্সে Ctrl+V।
  4. Deploy updates; "Successfully deployed" পর্যন্ত অপেক্ষা। Details-এ Verify JWT OFF থাকতে হবে।
ক্রম: SQL আগে, Edge Function পরে, সবশেষে GitHub।

৩. GitHub-এ আপলোড

  1. WLF-GitHub-v2.6.4-UPLOAD.zip extract করে ভেতরের ফোল্ডারে ঢুকুন।
  2. GitHub রিপো → Add file → Upload files → ভেতরের সব (Ctrl+A) টেনে দিন।
  3. Commit message: v2.6.4 admin panel, backup card, QMS excel → Commit changes।
  4. Actions-এ সবুজ ✓ পর্যন্ত অপেক্ষা। লাল হলে "FAILURE SUMMARY"-র নিচের লেখার স্ক্রিনশট দিন।

৪. যাচাই

  1. Ctrl+Shift+R; ⋮ মেনুর নিচে WLF v2.6.4।
  2. মেনুতে Admin Panel → R&I ইউজারদের কার্ড, নিচে curve। Full screen চেপে দেখুন।
  3. User Management-এ কোনো ইউজারের Permissions-এ "Admin Panel" টিক দিয়ে/তুলে দেখুন সে মেনু পায় কিনা।
  4. Storage & Backup-এ একটাই "Backup" কার্ড; নিচে "Settings and reference data"।
  5. QMS → QMS Data → একটা লিফট খুলে Download Excel: এক শিট; Excel-এ File → Print দিয়ে প্রিভিউ দেখুন।
  6. Storage & Backup → QMS data (Backup without Clear) চালিয়ে ফাইল খুলুন: শেষ শিট QMS Output Tables।
