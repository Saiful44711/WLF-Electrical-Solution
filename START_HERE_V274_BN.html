কী নতুন

  • Hardware Catalogue: মেনুতে এখন Administration-এর ভেতরে (Recycle Bin-এর পরে)। শুধু Super Admin খুলতে ও বদলাতে পারেন। আগে কারও "Hardware Catalogue edit" tick থাকলে SQL চালালে তা নিজে থেকে বাতিল হয়ে যাবে, আর ওই tick নতুন করে দেওয়াও যাবে না। QMS আর Damage Demand আগের মতোই catalogue থেকে তথ্য নেয়।
  • Hardware Catalogue change log (নতুন): catalogue-র পাতার নিচে। কে কোন সারি যোগ, বদল, মোছা বা ফেরত আনল, আগের আর নতুন মানসহ, সময় (Dhaka)। তারিখ filter, search আর Excel আছে। শুধু ক্রম বদলালে log হয় না। কে দেখবেন তা Super Admin ঠিক করেন: User Management-এ ওই ব্যক্তির অ্যাক্সেসে Hardware Catalogue change log tick দিন। তিনি শুধু log দেখবেন, catalogue বদলাতে পারবেন না।
  • Component change log: Usage Dashboard থেকে সরে Components Data-র পাতার উপরে এসেছে। Usage Dashboard-এর অ্যাক্সেস না থাকলেও চলবে। কে দেখবেন তা Super Admin ঠিক করেন: Component change log tick। শুধু এই tick থাকলে ব্যক্তি শুধু log দেখেন।
  • Announcement: Administration থেকে বেরিয়ে Admin Panel-এর ঠিক নিচে। কে দেখবেন তা Super Admin ঠিক করেন: Announcement tick। Recycle Bin আগের মতো শুধু Super Admin-এর।
