এই package-এ login-এর পর update menu পরীক্ষা করা হয়েছে এবং corrected file সঠিক tests folder-এ আছে। মূল folder-এর পুরোনো ভুল জায়গার file-টিও একই সঠিক test-এর দিকে পাঠানো হয়েছে।

এবার এই package-এর সব file ও folder একসঙ্গে আপলোড করুন। শুধু একটি আলাদা supabase-e2e.cjs আপলোড করলে এই নির্দেশনা সম্পূর্ণ হবে না।

১. ZIP extract করে সঠিক folder খুলুন

  1. WLF-v2.2.0-GitHub-Update-2026-11-07.zip-এ right-click → Extract All → Extract চাপুন।
  2. Extract হওয়া folder-এর ভেতরে ঢুকুন। একই জায়গায় web, tests, scripts, data, dist, shared, supabase, docs folder এবং package.json দেখতে পাবেন।
  3. ওই জায়গায় Ctrl+A চাপুন। সব file ও folder select হবে। নির্দেশনার HTML file select হলেও সমস্যা নেই।

২. আপনার বর্তমান repository-তে আপলোড করুন

  1. আপনার GitHub repository খুলুন
  2. Branch main আছে দেখুন। Repository-এর প্রথম পাতায় Add file → Upload files চাপুন। কোনো subfolder-এর ভেতরে upload শুরু করবেন না।
  3. কম্পিউটারে select করা সব file ও folder একসঙ্গে GitHub-এর upload area-তে drag করুন। নামগুলো আসা শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
  4. Upload list-এ নীচের ঠিক path-গুলো দেখুন। বিশেষভাবে tests/supabase-e2e.cjs থাকতে হবে।
Upload list-এ যা থাকবেঅর্থ
tests/supabase-e2e.cjsসংশোধিত browser test সঠিক জায়গায় যাচ্ছে
web/app.jsWebsite-এর source সঠিক জায়গায় যাচ্ছে
package.jsonRepository-এর মূল folder-এ যাচ্ছে
WLF-v2.2.0-GitHub-Update-2026-11-07/tests/...এভাবে দেখালে বাইরের folder-সহ দেওয়া হয়েছে। Upload বাতিল করে extracted folder-এর ভেতরের সব items drag করুন।
  1. Commit message লিখুন Update WLF v2.2.0 and correct browser test। Commit directly to the main branch নির্বাচন করে Commit changes চাপুন।

GitHub-এ ZIP ফাইলটি সরাসরি রাখলে code install হয় না। ZIP extract করার পর তার ভেতরের file ও folder দিন।

৩. নতুন deploy-এর ফল দেখুন

  1. GitHub Actions খুলুন
  2. একদম নতুন commit-এর Deploy WLF PWA to GitHub Pages run খুলুন।
  3. build এবং deploy দুটিই সবুজ ও সফল হতে হবে। হলুদ মানে এখনও চলছে; লাল মানে ব্যর্থ।
  4. লাল হলে build-এর মধ্যে যে step লাল, তার error message এবং run-এর link পাঠান। একই পুরোনো failed run বারবার চালালে file পরিবর্তন হয় না।

Releases box-এর “No releases published” দিয়ে website update যাচাই করবেন না। এই repository-এর বর্তমান workflow GitHub Pages website publish করে; আলাদা GitHub Release/tag তৈরি করে না।

বর্তমান Pages workflow আগে থেকেই repository-তে আছে এবং package তৈরির সময় যাচাই করা হয়েছে। এই package existing Saiful44711/WLF-Electrical-Solution project update করার জন্য।

৪. App-এ নতুন version ও সুবিধাগুলো দেখুন

  1. আগের website URL খুলুন। আগে লেখা draft save করে app reload করুন। পুরোনো interface থাকলে app-এর ⋮ → Update available · reload ব্যবহার করুন। Menu-তে WLF v2.2.0 দেখুন।
  2. Super Admin দিয়ে Technical Support-এর ছয় team, R&I Team Activity এবং R&I Project Manager খুলুন।
  3. সাধারণ user-এর জন্য User Management → user নির্বাচন → প্রয়োজনীয় নতুন module/team access দিন → Save role & access। সেই user-কে আবার sign in করতে বলুন।
  4. একটি activity entry এবং একটি project/task দিয়ে Save ও reopen পরীক্ষা করুন; project-এর PPTX download খুলে দেখুন।
  5. Storage & Backup → Excel → Backup without Clear পরীক্ষা করুন। PC-এর Excel এবং Google Drive-এর file মিলিয়ে নিন।

আপনার আগের যাচাইয়ে customized Commissioning form সংরক্ষিত ছিল। এই upload সেটি আবার SQL দিয়ে overwrite করে না।
