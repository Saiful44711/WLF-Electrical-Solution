Admin Panel নতুন ডিজাইন, সব dashboard-এ curve, QMS Special note: deployment নির্দেশিকা

আপনি laptop থেকে দেখবেন, তাই Admin Panel বড় স্ক্রিনের জন্য সাজানো; মোবাইলেও overflow ছাড়া চলে (চার্ট ভেতরে স্ক্রল হয়)।

কী বদলেছে (v2.6.6)

  • Admin Panel ফিল্টার: Dashboard ড্রপডাউন (R&I team activity, R&I Project Manager, Technical Support, Damage Demand, Supplier claim, QMS, Performance curves), R&I user ড্রপডাউন (All R&I users (compare) বা একজন), From/To, Apply, Download Excel, Full screen। একবারে একটাই dashboard দেখায়, তাই নিচে স্ক্রল করতে হয় না।
  • R&I team dashboard: সব user পাশাপাশি + curve। একজন user বাছলে তার টেবিল ও curve, সঙ্গে team average ড্যাশ-লাইন।
  • সব dashboard-এ curve: "Show" ড্রপডাউনে metric, "Range" ড্রপডাউনে 1 / 3 / 6 / 12 month (1 মাস = দৈনিক শেষ ৩০ দিন, 3 মাস = সাপ্তাহিক, 6/12 = মাসিক; শেষ বিন্দুর লেবেল "(to date)")। Together (এক চার্টে সব user) বা One by one (আলাদা ছোট চার্ট)। Hover/touch করলে tooltip; নাম চাপলে লাইন লুকায়।
  • QMS Special note: এখন আলাদা input "7 · Special note" ও আলাদা output "8 · SPECIAL NOTE" টেবিল। ঐচ্ছিক, সর্বোচ্চ ৫০০ অক্ষর। Excel রিপোর্ট, flat শিট, QMS Lifts শিটের "Special note" কলাম ও সব backup-এ আছে।

১. Supabase SQL (একটাই)

  1. Supabase → SQL Editor → New query।
  2. UPDATE_V266.sql খুলে Ctrl+A, Ctrl+C; Editor-এ পেস্ট; Run। RLS বার্তা এলে Run without RLS।
  3. ফলাফলে admin_series_ready, note_column_ready, v266_ready সব true থাকা উচিত।
V265 না চালিয়ে V266 চালালে "Run UPDATE_V265.sql first" আসবে। V264/V265 এখনও না চালালে ক্রমে চালান: V264 → V265 → V266।

২. Edge Function wlf-maintenance আবার deploy

  1. Supabase → Edge Functions → wlf-maintenance → Code; index.ts নির্বাচিত।
  2. কোড বক্সে ক্লিক করে Ctrl+A, Delete।
  3. প্যাকেজের edge-function/wlf-maintenance/index.ts Notepad-এ খুলে Ctrl+A, Ctrl+C; বক্সে Ctrl+V।
  4. Deploy updates; "Successfully deployed" পর্যন্ত অপেক্ষা। Verify JWT OFF থাকতে হবে।
ক্রম: SQL আগে, Edge Function পরে, সবশেষে GitHub।

৩. GitHub-এ আপলোড

  1. WLF-GitHub-v2.6.6-UPLOAD.zip extract করে ভেতরের ফোল্ডারে ঢুকুন।
  2. GitHub রিপো → Add file → Upload files → ভেতরের সব (Ctrl+A) টেনে দিন।
  3. Commit message: v2.6.6 Admin Panel redesign, curves, QMS special note → Commit changes।
  4. Actions-এ সবুজ ✓ পর্যন্ত অপেক্ষা। লাল হলে "FAILURE SUMMARY"-র নিচের লেখার স্ক্রিনশট দিন।

৪. যাচাই (laptop-এ)

  1. Ctrl+Shift+R; ⋮ মেনুর নিচে WLF v2.6.6।
  2. Admin Panel: Dashboard ড্রপডাউন বদলে প্রতিটা দেখুন; R&I user বদলান; Range 1/3/6/12 ও Together/One by one চেপে দেখুন; চার্টের উপর মাউস নিন।
  3. Download Excel চেপে "R&I user curves" শিট দেখুন।
  4. QMS Input: "7 · Special note"; Save করে QMS Data-য় "8 · SPECIAL NOTE" টেবিল; Excel-এও।
