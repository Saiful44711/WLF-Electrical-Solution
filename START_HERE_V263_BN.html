কী বদলেছে (v2.6.3)

  • My Profile: My activity টেবিল সরানো হয়েছে। Performance কার্ড, Work breakdown ও Project contribution আগের মতোই আছে।
  • Dashboard (Usage): R&I Team Activity ও R&I Project Manager কার্ড এবং Troubleshooting overview সরানো হয়েছে। Usage by feature ও Usage by user থাকছে।
  • Usage log ৭ দিন পর Drive-এ: ৭ দিনের পুরোনো সারিগুলো Excel হয়ে Google Drive-এর আলাদা ফোল্ডার WLF Activity backup — প্রজেক্ট-এ সেভ হয় ও ফেরত পড়ে যাচাই হয়। যাচাই ঠিক হলে তবেই ডেটাবেস থেকে মোছা হয়। হাতে মোছার অপশনও আগের মতো আছে (Download old log, Delete old log, তারিখ দিয়ে মোছা)।
  • নতুন Backup কার্ড (Storage & Backup): Technical Support, R&I, QMS, Damage Demand, Supplier Claim বাদে আপনার বাকি ডেটা এক ফাইলে: ইউজার ও পারমিশন, settings, support forms, R&I categories, Troubleshooting, Components Data, Documents Links, Hardware Catalogue, announcements। ফাইল Drive-এর আলাদা ফোল্ডার WLF Full Backup — প্রজেক্ট-এ যাচাই করে সেভ হয় এবং PC-তে নামে। History থেকে Download, Restore missing data, Delete আছে; এছাড়া PC-র ফাইল থেকেও Restore করা যায়।
  • পুরোনো কার্ডের নাম: "Support data backup" এখন Technical Support backup (restorable parts)।
  • Calculations: Save calculation, Records / Outbox ও Export latest CSV সরানো হয়েছে। শুধু Print / Save as PDF (A4) আছে। সার্ভারও আর ক্যালকুলেশন সেভ নেয় না।
  • R&I Team Activity Excel: Entry ID, Recorded status, Submitted by, Submitted at (UTC), Last updated (UTC) কলাম নেই।

আমি যা ধরে নিয়েছি

বিষয়অনুমান
Drive সেভ কখন চলেনিজে নিজে চলার জন্য Supabase-এর সময়সূচি (pg_cron) ব্যবহার করিনি, কারণ আপনার প্ল্যানে সেটা চালু কিনা আমি দেখতে পারি না। বদলে Super Admin যখন অ্যাপ খোলা রাখেন, তখন প্রতি ৬ ঘণ্টায় একবার চেক হয় ও ৭ দিনের পুরোনো সারি Drive-এ গিয়ে মোছা হয়। কয়েক দিন অ্যাপ না খুললেও পরের বার খুললে ধরে ফেলে।
সুরক্ষা জালযদি ৩০ দিনেও কেউ (Super Admin) অ্যাপ না খোলেন, ৩০ দিনের পুরোনো Usage সারি Drive-এ না গিয়েই স্বয়ংক্রিয়ভাবে মুছে যায়, যাতে ডেটাবেস ভরে না যায়।
একবারে কত সারিএক রাউন্ডে সর্বোচ্চ ২০,০০০ সারি এক Excel ফাইলে; বেশি থাকলে কয়েক রাউন্ডে যায়।
Backup কার্ডের Restoreশুধু যা নেই তা যোগ করে, কিছু মোছে না। ইউজার (accounts) Restore হয় না, কারণ ওগুলো Supabase Auth-এর। ইউজারের তালিকা শুধু তথ্য হিসেবে ফাইলে থাকে।
Backup কার্ডে "Clear" নেইএই ডেটা সাধারণত ছোট ও জরুরি, তাই মোছার অপশন দিইনি।
আগে সেভ করা ক্যালকুলেশনডেটাবেসের wlf_records-এ যা আছে তা আমি মুছিনি (আর ফেরানো যায় না বলে)। SQL-এর শেষ ফলাফলে saved_calculations_left দেখাবে কয়টা আছে। এগুলো খুব ছোট।
Calculations-এ PDFএখানে আগে কোনো PDF বাটন ছিল না। তাই বর্তমান Calculations পেজ ছাপা/PDF করার একটা বাটন দিয়েছি। ফলাফল দেখতে আগে Calculate চাপতে হবে।
Component change logএটা Usage log না, তাই এর আচরণ বদলাইনি।

১. Supabase SQL (একটাই)

  1. (ঐচ্ছিক কিন্তু ভালো) আগের মতো backup-kit দিয়ে একটা ব্যাকআপ নিন।
  2. Supabase → SQL Editor → New query।
  3. প্যাকেজের UPDATE_V263.sql খুলে Ctrl+A, Ctrl+C; Editor-এ পেস্ট; Run। RLS বার্তা এলে Run without RLS।
  4. ফলাফলে usage_archive_ready = true, full_backup_ready = true, v263_ready = true থাকা উচিত। saved_calculations_left-এ একটা সংখ্যা দেখাবে (ঠিক আছে)।
v2.6.2 না চালিয়ে V263 চালালে "Run UPDATE_V262.sql first" আসবে ও কিছু বদলাবে না। দুবার চালালেও সমস্যা নেই।

২. Edge Function wlf-maintenance আবার deploy (একটাই ফাইল)

Drive-এ নতুন ফোল্ডারে সেভ করার কোড এই ফাংশনে। Google-এর তিনটা secret আগের মতোই থাকবে, কিছু বদলাতে হবে না।

  1. Supabase ড্যাশবোর্ড → Edge Functions → wlf-maintenance।
  2. Code (বা Editor) ট্যাব খুলুন; বাঁ পাশে index.ts নির্বাচিত থাকবে।
  3. কোড বক্সে ক্লিক করে Ctrl+A, তারপর Delete।
  4. প্যাকেজের edge-function/wlf-maintenance/index.ts Notepad-এ খুলে Ctrl+A, Ctrl+C; Supabase-এর বক্সে Ctrl+V। (প্রথম লাইন // @ts-nocheck; লাল দাগ দেখালে চিন্তা নেই।)
  5. Deploy updates চাপুন; "Successfully deployed" আসা পর্যন্ত অপেক্ষা করুন।
  6. Details ট্যাবে Verify JWT বন্ধ (OFF) আছে কিনা দেখুন; না থাকলে বন্ধ করে Save changes।
ক্রম: SQL আগে, Edge Function পরে, সবশেষে GitHub।

৩. GitHub-এ আপলোড

  1. WLF-GitHub-v2.6.3-UPLOAD.zip extract করে ভেতরের ফোল্ডারে ঢুকুন।
  2. GitHub রিপো → Add file → Upload files → ভেতরের সব (Ctrl+A) টেনে দিন।
  3. Commit message: v2.6.3 usage archive, backup, no saved calculations → Commit changes।
  4. Actions-এ সবুজ ✓ পর্যন্ত অপেক্ষা। লাল হলে "FAILURE SUMMARY"-র নিচের লেখার স্ক্রিনশট দিন।

৪. যাচাই

  1. Ctrl+Shift+R / অ্যাপ রিলোড; ⋮ মেনুর নিচে WLF v2.6.3।
  2. My Profile-এ My activity টেবিল নেই।
  3. Dashboard-এ R&I কার্ড ও Troubleshooting overview নেই।
  4. Calculations-এ শুধু Print / Save as PDF (A4)।
  5. Storage & Backup → Backup → Backup now: ফাইল নামবে, "verified copy…" লেখা আসবে, নিচের history-তে সারি আসবে। Drive-এ WLF Full Backup — … ফোল্ডারে ফাইল দেখুন।
  6. Super Admin হিসেবে অ্যাপ খোলা রাখলে (৩ সেকেন্ড পর) যদি ৭ দিনের পুরোনো Usage সারি থাকে, একটা বার্তা আসবে "…saved to Google Drive (WLF Activity backup)…"। Drive-এ WLF Activity backup — … ফোল্ডারে Excel দেখুন।
