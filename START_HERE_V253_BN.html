কী বদলেছে

  • অ্যাপ খুললেই My Profile: লগইনের পর প্রথম পাতা এখন My Profile।
  • মেনুতে লাল সংখ্যা:
    • My Profile: আপনার কাছে Forward হওয়া (এখনো Receive না করা) request + না-পড়া Announcement।
    • Damage Demand: সব টিম মিলিয়ে মোট Pending demand (যাদের Damage Demand দেখার অনুমতি আছে শুধু তারা দেখেন)।
  • Damage Demand-এর নিচের Demand / Dashboard মেনু থেকে সরানো হয়েছে। পাতার উপরের Demand / Dashboard বোতাম আগের মতো আছে।
  • Announcement (Administration, শুধু Super Admin): শিরোনাম, বার্তা, কোন কোন Section (বা All sections), ইচ্ছা হলে শেষ তারিখ। Publish করলে ওই Section-এর সবাই My Profile-এর উপরে কার্ড, মেনুতে লাল সংখ্যা আর ফোন/PC notification পান। Read চাপলে সংখ্যা কমে। Super Admin দেখেন কতজন পড়েছেন ও কারা পড়েছেন; Edit, Delete করতে পারেন।
  • Recycle Bin (Administration, শুধু Super Admin): অ্যাপে যা-ই ডিলিট হোক — Support request, R&I entry, Project, Project task, Troubleshooting entry, Document link, Document sub menu (ভেতরের folder/link সহ), Folder, Announcement — সব এখানে জমা থাকে। Restore করলে আগের জায়গায় ফিরে যায়। Delete permanently চাপলে কয়টা মুছবে তা দেখিয়ে নিশ্চিত হতে বলে। Empty bin-এ ঘরে DELETE লিখতে হয়। নিজে থেকে কিছুই মোছে না। কে কবে কয়টা চিরতরে মুছেছেন শুধু সেটুকু লগে থাকে (বিষয়বস্তু নয়)।
  • Usage Dashboard: সংখ্যা ও নতুন Activity log এখন শেষ ৩০ দিনের; User বেছে ফিল্টার করা যায়। ৩০ দিনের পুরনো লগ থাকলে Super Admin হলুদ সতর্কবার্তা দেখেন: আগে Download old log (Excel), তারপর Delete old log… (DELETE লিখে)। নিজে থেকে কিছু মোছে না।
  • Dashboard এখন Management Dashboard (যাদের আগে Dashboard অনুমতি ছিল তারাই দেখেন): ① R&I Team Activity — প্রতিটা ফর্মে কতগুলো ও কে কয়টা, ② R&I Project Manager — Lead অনুযায়ী প্রজেক্ট ও Status, ③ Technical Support — টিম অনুযায়ী Solved/Not solved/Open, কে কয়টা Receive/Solve/Forward করেছেন, ১২ মাসের কার্ভ, ④ Damage Demand — টিম অনুযায়ী, সবচেয়ে বেশি নষ্ট হওয়া ১০টা কম্পোনেন্ট, ১২ মাসের কার্ভ, ⑤ QMS, ⑥ Supplier claim (শীঘ্রই)। ডিফল্ট এই মাস, From/To বদলানো যায়। Download Excel আছে। পুরনো Activity log এই পাতায় আর নেই।
  • My Profile → My work breakdown: শুধু নিজের কাজ — পাঠানো Support request, যে Support handle করেছেন (Receive/Solve/Forward), R&I ফর্ম অনুযায়ী entry, প্রজেক্ট ও নিজের task, Damage Demand, QMS, কোন টুল কতবার। ডিফল্ট এই মাস।

২. Supabase-এ ডাটাবেস আপডেট

  1. Supabase → SQL Editor → New query।
  2. UPDATE_V253.sql Notepad-এ খুলে Ctrl+A, Ctrl+C, পেস্ট করে Run। RLS বার্তা এলে Run without RLS।
  3. ফলাফলের সারি:
    কলামযা থাকা উচিত
    recycle_bin_readytrue
    items_in_recycle_binএকটা সংখ্যা (০ বা বেশি) — আগেই যেগুলো ডিলিট করা ছিল সেগুলো এখন Bin-এ
    announcements_readytrue
    management_dashboard_readytrue
    v253_readytrue
একটাই transaction, দুবার চালালেও ক্ষতি নেই। এই SQL কিছুই মোছে না।
আগে ডিলিট করা Support request-এ "কে ডিলিট করেছেন" দেখা যাবে; আগে ডিলিট করা R&I entry, Project, Troubleshooting-এ সেই তথ্য আগে রাখা হতো না, তাই "Deleted by" ঘর ফাঁকা থাকবে। আগে ডিলিট করা Document, Folder, Sub menu, Project task ডাটাবেস থেকে আগেই মুছে গেছে — সেগুলো Bin-এ আসবে না।

৩. GitHub-এ ফাইল আপলোড

  1. WLF-GitHub-v2.5.3-UPLOAD.zip extract করে WLF-v2.5.3-upload ফোল্ডারে ঢুকুন।
  2. GitHub repo → Add file → Upload files → ভেতরের সব (Ctrl+A) টেনে দিন (১০০টির কম ফাইল)।
  3. Commit message: v2.5.3 Recycle bin, announcements, management dashboard → Commit changes।
  4. Actions-এ সবুজ ✓ পর্যন্ত অপেক্ষা।
ক্রম: আগে SQL (ধাপ ২), তারপর GitHub (ধাপ ৩)। উল্টো হলে নতুন পাতায় "Unsupported action" দেখাবে — SQL চালালেই ঠিক হবে।

৪. লাইভ সাইটে যাচাই

  1. Ctrl+F5 বা অ্যাপ বন্ধ করে আবার খুলুন; ⋮ মেনুর নিচে WLF v2.5.3। লগইনের পর My Profile খোলে।
  2. মেনুতে Damage Demand-এর নিচে Demand / Dashboard নেই; Pending থাকলে পাশে লাল সংখ্যা।
  3. Administration-এ Announcement ও Recycle Bin।
  4. Announcement → All sections টিক রেখে একটা পরীক্ষামূলক বার্তা Publish → অন্য ইউজারের My Profile-এ কার্ড ও মেনুতে লাল সংখ্যা → Read চাপলে কমে। পরে Delete করে দিন (Bin-এ যাবে)।
  5. Usage Dashboard → উপরে Activity log · last 30 days।
  6. Dashboard → ৬টা অংশ, এই মাসের তারিখ।

Recycle Bin ব্যবহার

  • Type আর Search দিয়ে খুঁজুন।
  • Restore: জিনিসটা আগের জায়গায় ফিরে যায়। Project task ফেরাতে হলে তার Project চালু থাকতে হবে (Project ডিলিট হয়ে থাকলে আগে Project Restore করুন)। Document link বা Folder ফেরাতে হলে তার Sub menu থাকতে হবে।
  • Delete permanently: একটা, বা টিক দিয়ে কয়েকটা একসাথে। Support request চিরতরে মুছলে তার history আর Damage demand-ও মুছে যায়।
  • Empty bin: সব কিছু চিরতরে, DELETE লিখে নিশ্চিত করতে হয়।
  • নিচে Permanent delete log: কে, কবে, কোন ধরনের কয়টা।

Announcement ব্যবহার

  • নির্দিষ্ট Section-এ পাঠাতে All sections টিক তুলে দিয়ে Section টিক দিন।
  • Show until দিলে সেই দিনের পর আর দেখায় না (Bin-এ যায় না, তালিকায় "Ended")।
  • Edit-এর সময় Send again as new টিক দিলে সবাই আবার না-পড়া হিসেবে পায় আর notification যায়; টিক না দিলে শুধু লেখা বদলায়।
  • Notification যাবে শুধু যারা My Profile → Notifications চালু রেখেছেন তাদের কাছে।
