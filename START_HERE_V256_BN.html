ডাটাবেজের জায়গা (free plan)

Activity log-এর প্রতিটা সারি মোটামুটি 150–250 byte। 300 user দিনে 30টা কাজ করলে দিনে প্রায় 2 MB, মাসে প্রায় 55–60 MB। Free plan-এ ডাটাবেজ 500 MB। তাই মাসে একবার পুরনো log মুছুন।

  1. এখন কত জায়গা লাগছে: SQL Editor-এ চালান
    select pg_size_pretty(pg_database_size(current_database())) as total, pg_size_pretty(pg_total_relation_size('public.wlf_usage')) as activity_log;
  2. মোছার পর size সত্যিই কমাতে (অনেক সারি মোছার পর, কম ব্যবহারের সময়ে):
    vacuum full public.wlf_usage;
    এটা চলার কয়েক সেকেন্ড টেবিল lock থাকে। শুধু delete করলে Postgres খালি জায়গা নতুন সারির জন্য রেখে দেয়: ডাটাবেজ আর বাড়ে না, কিন্তু size-এর সংখ্যা কমে না।

Component change log খুব ছোট (বদল কম হয়), তাই স্থায়ীভাবে রাখা হয়।
