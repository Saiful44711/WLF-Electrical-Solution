কী বদলেছে

  • টিম কার্ডে লাল সংখ্যা: Technical Support-এর প্রতিটা টিম কার্ডের কোণে মেনুর মতো লাল সংখ্যা (unsolved request)। ০ হলে লুকানো।
  • My Profile → Forwarded to you: আপনার কাছে Forward হওয়া কিন্তু এখনো Receive না করা request-এর তালিকা, প্রোফাইলের একদম উপরে। Reference, টিম, প্রজেক্ট, Lift, কে পাঠাল, মন্তব্য দেখায়। চাপলে request খোলে; Receive করলে তালিকা থেকে সরে যায়। (Push notification আগের মতোই আসবে।)
  • Damage Demand টিম-ভিত্তিক: Demand তালিকার উপরে All teams / Commissioning / After Sales / Installation / Factory Maintenance ট্যাব, পাশে লাল Pending সংখ্যা। Receive এখন টিম অনুযায়ী (নিচে ধাপ ৪)।
  • Component Selection রিপোর্ট: "2. Recommended ARKEL Control System" → "2. Recommended MOT Control System"।
  • Technical Support-এর Problem Category: Commissioning, After Sales, Production, QC, Factory Maintenance ফর্মে আপনার Excel-এর ৩৬টা category। Installation ফর্ম বদলায়নি।
    • প্রথম ৫টা category (MOT drive Error, NICE3000+ drive error, NICE900 door drive error, NBSL-G220 door drive error, AVR related issue) বাছলে Problem Sub-Category popup খোলে, খোঁজার বক্সসহ। একটা বাছাই বাধ্যতামূলক। তালিকা: MOT ১০০, NICE3000+ ১৫৭ ("Err15 · Sub 1" আকারে), NICE900 ২২, NBSL-G220 ২৬, AVR ৮।
    • অন্য category-তে Sub-Category আসে না। "Others" বাছলে নাম লেখার বক্স।
    • বানান ঠিক করা হয়েছে: dirve→drive, releted→related, isuue→issue, Proximitry→Proximity, Breaking resistor→Braking resistor। "Centra load cell" যেমন ছিল তেমন।
    • পুরনো request-এ পুরনো category যেমন ছিল তেমনই থাকে।
  • Sub-Category এডিট (Super Admin): টিম খুলে Manage form fields → "Problem Sub-Category" ঘরের নিচে প্রতিটা category-র তালিকা (এক লাইনে একটা)। বদলান, লাইন মুছুন, নতুন লাইন দিন। অন্য category-র জন্য নতুন তালিকা: "Add a list for…" থেকে category বেছে + Add list। কোনো তালিকা পুরো খালি করলে সেটা মুছে যায়। শেষে Save form fields। প্রতিটা টিমের ফর্ম আলাদা, তাই যে টিমে দরকার সেখানে বদলাবেন।
  • Request access: সব ঘরের পাশে লাল *। খালি ঘর থাকলে লাল হয়ে যায়, কার্সর প্রথম খালি ঘরে যায়, উপরে কোন কোন ঘর বাকি তা লেখা থাকে। সার্ভারও Name, Employee ID আর সঠিক Section ছাড়া request নেয় না। একই ID দিলেও জমা নেয়, User Management-এ লাল "Duplicate ID" দেখায়।

২. Supabase-এ ডাটাবেস আপডেট

  1. Supabase → SQL Editor → New query।
  2. UPDATE_V252.sql Notepad-এ খুলে Ctrl+A, Ctrl+C, পেস্ট করে Run। RLS বার্তা এলে Run without RLS।
  3. ফলাফলে চারটা কলামই true:
    কলামমানে
    problem_sub_category_ready৫টা ফর্মে Problem Sub-Category
    problem_categories_ready৫টা ফর্মে নতুন ৩৬টা category
    damage_receive_by_team_ready৪টা টিম-ভিত্তিক Receive option; পুরনো Receive যাদের ছিল তারা চারটাই পেয়েছেন
    v252_readyনতুন সার্ভার-নিয়ম চালু
একটাই transaction, দুবার চালালেও ক্ষতি নেই। দ্বিতীয়বার চালালে Super Admin-এর করা Sub-Category এডিট মুছে যায় না।
SQL চালানোর মুহূর্তে কেউ Support ফর্ম খোলা রেখে Submit করলে "Form changed" আসতে পারে। ফর্ম আবার খুললেই ঠিক।

৩. GitHub-এ ফাইল আপলোড

  1. WLF-GitHub-v2.5.2-UPLOAD.zip extract করে WLF-v2.5.2-upload ফোল্ডারে ঢুকুন।
  2. GitHub repo → Add file → Upload files → ভেতরের সব (Ctrl+A) টেনে দিন (১০০টির কম ফাইল)।
  3. Commit message: v2.5.2 Problem sub-category, team badges, damage receive by team → Commit changes।
  4. Actions-এ সবুজ ✓ পর্যন্ত অপেক্ষা।
ক্রম: আগে SQL (ধাপ ২), তারপর GitHub (ধাপ ৩)।

৪. Damage Demand Receive অনুমতি (Super Admin)

  1. User Management → ইউজার খুলুন → Damage Demand অংশ।
  2. "Dispatch / Receive demands"-এর বদলে এখন চারটা টিক: Receive demands · Commissioning / After Sales / Installation / Factory Maintenance। যে টিমের demand তিনি Receive করবেন শুধু সেগুলোতে টিক দিন। (Demand দেখার জন্য "Demand" টিকও লাগবে, আগের মতো।)
  3. Save user & access। পরিবর্তন Change history-তে জমা থাকে।

যিনি একটা টিমের Receive পাননি, তিনি সেই টিমের demand দেখতে পারবেন কিন্তু "Receive demand" বোতাম পাবেন না; সার্ভারও আটকাবে।

৫. লাইভ সাইটে যাচাই

  1. Ctrl+F5 বা অ্যাপ বন্ধ করে আবার খুলুন; ⋮ মেনুর নিচে WLF v2.5.2।
  2. Technical Support: টিম কার্ডে লাল সংখ্যা।
  3. Commissioning → + New request → Problem Category NICE3000+ drive error → popup → "Err20" লিখে খুঁজুন → একটা বাছুন।
  4. R&I ইউজার: My Profile-এর উপরে "Forwarded to you"।
  5. Damage Demand → Demand: টিম ট্যাব।
  6. লগআউট করে Request access-এ খালি অবস্থায় Send request চাপুন: সব ঘর লাল।
  7. Component Selection রিপোর্টে "Recommended MOT Control System"।
