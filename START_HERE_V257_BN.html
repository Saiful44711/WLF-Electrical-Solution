কী বদলেছে

  • Technical Support পর্দা এখন দুই ভাগে, পুরো প্রস্থ জুড়ে। বাঁ ৫০%: নিচে ভাঁজ করা যায় এমন Filters প্যানেল, তার নিচে request-এর তালিকা। ডান ৫০%: খোলা request-এর বিস্তারিত। + New request চাপলে ফর্মটা ডান দিকে খোলে (তখন বিস্তারিত সরে যায়, ফর্ম জমা বা Close করলে ফিরে আসে)। ডান পাশ স্ক্রল করলেও জায়গায় থাকে। পাশের ফাঁকা জায়গা কমানো হয়েছে।
  • ফর্মের ঘর ছোট: ঘরের উচ্চতা কমানো, ছোট ঘর দুই কলামে পাশাপাশি। Project Address আর Problem Details ২ লাইনে শুরু হয়, লিখলে নিজে বড় হয়। ফোনে এক কলাম; ফর্ম খুললে সবার আগে ফর্ম আসে, Filters বন্ধ থাকে (চাপলে খোলে, পছন্দটা মনে থাকে)।
  • লাল চিহ্ন: যিনি request দিয়েছেন তাঁর My Profile-এর পাশে (সংখ্যা সহ) আর উপরের ⋮ মেনুতে লাল চিহ্ন থাকে, যতক্ষণ তাঁর কোনো request Solved না হয়। Pending, Received, Forwarded আর Not Solved সবই "বাকি" ধরা হয়।
  • Push notification (request-দাতাকে): R&I user request Solved, Not Solved করলে বা Forward করলে। Forward করলে লেখা থাকে কাকে forward করা হয়েছে। Receive করলে কিছু যায় না। যিনি নিজে কাজটা করেছেন তিনি পান না।
  • Damage Demand: ওই request-এর demand যখন Dispatch user Receive করেন, request-দাতা push পান ("Your Damage Demand was received", demand নম্বর, item আর পরিমাণ সহ)।
  • Activity log নিজে থেকে মুছে যায়: ৭ দিনের পুরনো সারি স্বয়ংক্রিয়ভাবে মোছা হয়। যাচাই হয় সর্বোচ্চ ঘণ্টায় একবার, যখন কেউ অ্যাপ ব্যবহার করেন (আলাদা cron লাগে না)। কত সারি মোছা হলো তা Permanent delete log-এ ("automatic") থাকে। Excel কপি লাগলে ৭ দিন পার হওয়ার আগে নামিয়ে নিন। মোছার পর ফাইলের size কমাতে চাইলে v2.5.6-এর গাইডের vacuum full public.wlf_usage;।
খেয়াল রাখুন: আগে ৭ দিনের পুরনো সারি রেখে দেওয়া হতো। এই আপডেটের পর প্রথমবার কেউ অ্যাপ ব্যবহার করলেই ৭ দিনের পুরনো সব সারি মুছে যাবে। দরকার হলে SQL চালানোর আগে Usage Dashboard থেকে Excel নামিয়ে নিন।
