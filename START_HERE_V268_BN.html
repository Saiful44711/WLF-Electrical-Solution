Technical Support Excel, Catalogue import (model replace) ও QMS QR কোড: deployment নির্দেশিকা

Technical Support-এর Excel এখন পরিষ্কার Excel Table, CSV বোতাম নেই। Hardware Catalogue import এখন model-এর পুরো table replace করে। প্রতিটি lift-এর QR কোড সেভ ও প্রিন্ট করা যায়।

কী বদলেছে (v2.6.8)

  • Technical Support Excel: ছয়টি ফর্মেই Excel Table থেকে হলুদ-চিহ্নিত কলামগুলো বাদ: Request ID, Submitted by, Submitted at, Last updated, Assigned to, Solved by (ও আগের CSV-র Activity history)। থাকে: Workflow status, Solved at, Solution ও ফর্মের সব প্রশ্ন (Date, Name, ID, Project, Lift ID, Address, Controller, Problem…)। এটা শুধু Technical Support মেনুর Excel-এ প্রযোজ্য; Storage & Backup-এর Excel আগের মতো সব কলামসহ।
  • CSV বোতাম: Technical Support-এর "Download filtered CSV" সরানো হয়েছে। (Performance dashboard-এর আলাদা CSV বোতাম রাখা হয়েছে, কারণ ওটার Excel বিকল্প নেই।)
  • Hardware Catalogue → "Import model data": আগের "Import CSV" শুধু সারি যোগ করত। এখন ফাইলে যে Control system + Model আছে, তার পুরো table replace হয়: পুরোনো সব সারি যায়, ফাইলের সারি বসে। ফাইলে যে model নেই সেটা অক্ষত থাকে। ফাইলে নতুন model থাকলে যোগ হয়। Excel (.xlsx) ও CSV দুটোই নেয়।
  • আগে preview: "Check file" চাপলে প্রতি model-এর "এখন কত সারি / ফাইলে কত সারি / কী হবে" দেখায়। কিছুই বদলায় না। তারপর "Replace these models" চাপলে তবেই বদলায়।
  • QMS QR কোড: QMS Data-তে lift খুললে নতুন "QR code · control panel label" অংশ। QR-এ থাকে: Lift ID, Project, Controller model, Motor, COP display, LOP display, Transom display, AVR capacity ও WLF-এর লিংক। Serial number QR-এ নেই। বোতাম: Save QR (PNG) (পিসি ও মোবাইলে, নিচে Lift ID লেখাসহ) ও Print label।
  • QR স্ক্যান: যেকোনো মোবাইল ক্যামেরা/স্ক্যানারে লগইন ছাড়া লেখাগুলো পড়া যায়। শেষ লাইনের লিংক খুললে WLF-এ সাইন-ইন করার পর ওই lift সরাসরি খোলে (QMS permission লাগে)। পুরো output table ও serial দেখতে এই লিংক লাগে।

Import ফাইলের নিয়ম

  • প্রথম সারি হেডার: Control system, Model, Group, Hardware, Spec, Item code, Item name, Brand, Supplier, Price। Control system ও Model কলাম থাকতেই হবে।
  • Control system ও Model খালি সারি বাদ যায়। এক ফাইলে সর্বোচ্চ ২০০০ সারি।
  • Excel ফাইলের প্রথম sheet পড়া হয়। Catalogue-এর "Export" করা ফাইলের গঠনই এই import-এর গঠন, তাই export করে বদলে আবার import করা যায়।
  • Control system ও Model মেলানো হয় বড়-ছোট হাতের অক্ষর উপেক্ষা করে।
  • সাবধান: কোনো model-এর ফাইল দিলে ওই model-এর সব সারি বদলে যায়। ফাইলে সব সারি না থাকলে বাদ পড়া সারি মুছে যায়। তাই আগে preview-র "Rows now" ও "Rows from file" মিলিয়ে নিন। মুছে যাওয়া সারি Hardware Catalogue থেকে সরে যায়; আগে সেভ করা QMS record নিজের কপি রাখে, তাই বদলায় না।

QR সম্পর্কে জানার বিষয়

  • QR-এর লেখা lift সেভ করার সময়ের তথ্য থেকে বানানো। lift edit করলে QR বদলাতে পারে। তাই পরিবর্তনের পর আবার সেভ করে নতুন QR ছাপুন।
  • QR-এ থাকা লেখা সবাই পড়তে পারে (লগইন লাগে না)। ফলে Lift ID ও Project name সবাই দেখবে। Address, customer, price, serial QR-এ নেই।
  • QR-এ সব output table ঢোকানো সম্ভব নয় (QR-এর ধারণক্ষমতা সীমিত)। সম্পূর্ণ table লিংক খুলে WLF-এ দেখতে হয়।
  • COP display = COP-এর "COP Display" group-এর hardware নাম। Motor model = নির্বাচিত motor-এর "Motor Model" মান; motor না বাছা থাকলে "—" দেখায়।
  • ছাপার সময় QR অন্তত ২.৫ সেমি বর্গ রাখুন। প্রিন্টে স্পষ্ট না হলে বড় করে ছাপুন।

যা এখানে যাচাই করা যায়নি

  • আসল Supabase-এ SQL চালানো (এখানে একই Postgres ভার্সনের পরীক্ষা-ডাটাবেসে চালিয়ে দেখা হয়েছে)।
  • আসল ফোনের ক্যামেরায় স্ক্যান ও কাগজে ছাপা QR। কম্পিউটারে QR ছবি decode করে লেখা মিলিয়ে দেখা হয়েছে।
  • Android APK-তে PNG সেভ ও প্রিন্ট। ব্রাউজারে (PC ও মোবাইল আকারে) পরীক্ষিত।
  • আপনার আসল Catalogue-এর আসল Excel দিয়ে import। পরীক্ষার ফাইল দিয়ে হয়েছে।
