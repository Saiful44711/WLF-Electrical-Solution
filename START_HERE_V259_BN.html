কী বদলেছে

  • Hardware Catalogue (নতুন মেনু): QMS আর Damage Demand-এর জন্য একটাই ডাটাবেস। আপনার Excel থেকে MOT (৬ মডেল) ও NICE3000+ (৭ মডেল), LOP, COP, Transom ও Other components ঢোকানো আছে। AVR ক্যাটাগরিতে ৮টা সাইজ (15, 20, 30, 40, 60, 80, 100, 120 KVA), প্রতিটায় ১০টা ফাঁকা সারি: Item code, Name, Spec, Value, Supplier, Brand। Super Admin সারি যোগ/এডিট/ডিলিট, নতুন মডেল যোগ (চাইলে আরেক মডেলের কপি), নাম বদল, মডেল ডিলিট, Excel এক্সপোর্ট, CSV ইমপোর্ট করতে পারেন।
  • Raise Damage Demand: সবার আগে Component model ও Supplier name। Item code, name, spec ক্যাটালগ থেকে আসে; R&I শুধু আসল যন্ত্রাংশ বেছে Quantity দেয়। Support request-এর Control System ও Problem Category অনুযায়ী যন্ত্রাংশ "Suggested" দেখায়। ক্যাটালগে না থাকলে "Not in the catalogue" টিক দিয়ে হাতে লেখা যায়। Damage Demand ও Supplier Claim আগের মতোই।
  • QMS (নতুন রূপ): প্রতি লিফটের জন্য একটা রেকর্ড, ডেলিভারির আগে QM team ভরবে। Lift ID কোম্পানিতে unique (বড়/ছোট হাতের লেখা বা ফাঁকা জায়গায় আলাদা ধরা হয় না)। ফর্মের ৫ ভাগ: Project information, Control system ও serial number, Selected motor (Component Selection-এর মতো একই ইনপুট), LOP/COP/Transom/Travelling cable, Other components (AVR সহ)।
  • QMS Data: Lift ID, Project বা Item code দিয়ে খুঁজুন। পাঁচটা টেবিলে ফল দেখাবে; Download Excel (একটা লিফট বা সব ফলাফল)। সেভের সময় Item code/name/spec/brand-এর কপি রেকর্ডে থেকে যায়, তাই ৫-১০ বছর পরে ক্যাটালগ বদলালেও পুরোনো লিফটের আসল তথ্য ঠিক থাকে।
  • Edit ও Delete: আলাদা দুটো permission, Super Admin যাকে টিক দেবে সে-ই পারবে (নিচে ৫ নম্বর)। প্রতিটা বদল Change history-তে লেখা থাকে।
  • Dashboard-এর QMS কার্ড এখন লিফট রেকর্ডের সংখ্যা দেখায়।
আপনার Excel-এ যা সংশোধন করেছি: NICE3000+ শিটের 196–199 সারি (Encoder Card, SL 21–24) "11 kW" লেখা, কিন্তু ওগুলো 45 kW ব্লকের শেষে (45 kW-এর SL 1–20 পরে)। আমি ওগুলো 45 kW-এ রেখেছি; ফলে 45 kW-এ 24টা সারি, বাকি মডেলের মতো। ভুল হলে ক্যাটালগে মডেল বদলে নিন।
যা এই ভার্সনে নেই (স্পষ্ট করে বলছি): (১) এক Demand-এ একাধিক যন্ত্রাংশ: ডাটাবেসে এক request-এ একটাই Demand, তাই একটাই আইটেম। (২) পুরোনো "Component Tracking" তালিকা আর দেখা যায় না; ডাটাবেসে রেকর্ড থেকে যায়, মোছা হয়নি। (৩) ক্যাটালগে ইমপোর্ট শুধু CSV (Excel-এ Save as CSV)। (৪) মুছে ফেলা লিফট Recycle bin-এ আসে না, শুধু আড়াল হয়; Lift ID আবার ব্যবহার করা যায়। (৫) MOTCUBE-এর কোনো যন্ত্রাংশ আপনার Excel-এ ছিল না, তাই MOTCUBE মডেল ফাঁকা; Super Admin "New component model" দিয়ে যোগ করবেন।
Selected motor অংশ Component Selection-এর ডেটা ব্যবহার করে। যে QM user-এর Component Selection অপশন নেই, তার ফর্মে "Search motors" বাটন বন্ধ থাকবে; তাকে ওই অপশনটা টিক দিন।

৪. যাচাই

  1. Ctrl+F5; ⋮ মেনুর নিচে WLF v2.5.9।
  2. Super Admin হিসেবে বাঁ মেনুতে Hardware Catalogue → AVR → AVR 20 KVA: ১০টা ফাঁকা সারি। একটায় Edit দিয়ে কিছু লিখে Save করে দেখুন।
  3. QMS → QMS Input: Lift ID, Project, Delivery date, Control system MOT → Controller model MOT 7.5 kW বেছে Save। একই Lift ID আবার দিলে "Lift ID already exists" আসবে।
  4. QMS Data → Lift ID লিখে Search → পাঁচটা টেবিল → Download Excel।
  5. একটা request Receive করে Hardware Issue = Yes দিন: Raise Damage Demand-এ Component model ও Supplier আগে, তারপর যন্ত্রাংশ বেছে Quantity দিয়ে Submit।
