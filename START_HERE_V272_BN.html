কী নতুন

  • Request access: Name, Employee ID বা Section-এর কোনোটা খালি থাকলে সার্ভার অনুরোধ নেয় না, অ্যাপের পুরোনো সংস্করণ থেকে এলেও না। Employee ID আর Section ছাড়া কোনো অ্যাকাউন্ট Approve করা যায় না। চেষ্টা করলে লেখা আসে "Fill in the Employee ID and the Section before approving this account."
  • Monthly Excel backup (Storage & Backup-এ নতুন কার্ড):
    • প্রতি মাসের ১ তারিখ রাতে ছয়টা module-এর আগের মাসের Excel তৈরি হয়: Technical Support, R&I Team Activity, R&I Project Manager, QMS Data, Damage Demand, Supplier Claim।
    • ফাইলগুলো যায় Google Drive-এর Monthly Excel Backup ফোল্ডারে, প্রতিটা module-এর আলাদা ফোল্ডারে।
    • কিছুই মোছে না।
    • Make backup now দিয়ে যেকোনো মাসের backup হাতেও বানানো যায়।
    • Backup কার্ডের বোতামগুলো আগের মতোই আছে।
  • মাসিক রিপোর্ট: Drive-এ এখন একটাই মূল ফোল্ডার, Monthly Analysis Report। তার ভেতরে তিনটা রিপোর্টের আলাদা ফোল্ডার। আগের আলাদা ফোল্ডারগুলো ফাইলসহ নিজে থেকেই এর ভেতরে চলে আসবে, যখন পরের রিপোর্টটা বানানো হবে।
  • Excel-এর চেহারা: কলামের চওড়া লেখা অনুযায়ী ঠিক হয়। লম্বা লেখা পরের লাইনে যায় (wrap) আর সারি সেই অনুযায়ী উঁচু হয়।
  • System status কার্ড: অ্যাপ, ডাটাবেস আর Edge Function কোন ভার্সনে চলছে দেখায়। না মিললে লাল লেখায় বলে দেয় কী করতে হবে।
  • Error log কার্ড: কারও অ্যাপে error হলে এখানে জমা হয়: কখন, কে, কোন পাতা। ৭ দিন পর নিজে থেকে মুছে যায়, প্রতি অ্যাকাউন্টের ঘণ্টায় সর্বোচ্চ ৩০টা জমা হয়। শুধু Super Admin দেখতে পারেন।
  • নিরাপত্তা নিয়ম (Content-Security-Policy): অ্যাপ এখন শুধু নিজের ফাইলের কোড চালায়।
  • গতি: তারিখের index যোগ হয়েছে। QMS snapshot পরিষ্কারের ফাংশন এখন অনেক কম মেমোরি নেয়।
  • রিপোর্টে space-এর সমস্যা স্থায়ীভাবে ঠিক: Edge Function-এর ফাইল এখন শুধু সাধারণ ইংরেজি অক্ষরে লেখা, তাই copy-paste করলে কিছু বদলায় না।
