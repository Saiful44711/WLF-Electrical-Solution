Admin Panel: QMS ও Supplier Claim ড্যাশবোর্ড — deployment নির্দেশিকা

একটা SQL ফাইল চালাতে হবে, আর GitHub-এ ফাইল আপলোড করতে হবে। Edge Function বদলাতে হবে না। ডাটাবেসে নতুন কোনো টেবিল বা তথ্য যোগ হয় না: ড্যাশবোর্ড শুধু আগের তথ্য পড়ে।

কী নতুন

  • Admin Panel → Dashboard → QMS
    • উপরে চারটা সংখ্যা: Lifts recorded, Projects, Control systems, আর All lift records।
    • Control system অনুযায়ী টেবিল: কোন control system কয়টা project-এ আর কয়টা lift-এ গেছে, মোটের কত শতাংশ, আর কোন controller model কয়টা।
    • Hardware category অনুযায়ী project tracking: Hardware category বাছুন (Controller, Motor, AVR, Circuit Breaker, Control PCB, LOP, COP Display, Transom Display…)। প্রতিটা model-এর item code, brand, কয়টা project আর কয়টা lift দেখাবে। Sites চাপলে সেই model যেসব project আর Lift ID-তে গেছে তার তালিকা খোলে।
    • Search ঘর: model, item code, project বা Lift ID লিখে খোঁজা যায়।
    • Lifts: "Recorded in this period" (From–To তারিখের মধ্যে রেকর্ড হওয়া lift) অথবা "All lift records" (সব lift)। কোনো পুরোনো model কোথায় কোথায় আছে খুঁজতে চাইলে All lift records বেছে নিন।
  • Admin Panel → Dashboard → Supplier claim
    • উপরে পাঁচটা সংখ্যা: supplier-কে পাঠানো claim, Pending, Received (শতাংশসহ), মোট unit, আর আজ পর্যন্ত মোট Pending (তারিখ যা-ই হোক)।
    • Supplier অনুযায়ী টেবিল: প্রতিটা supplier-এর claim, Pending, Received, unit, মোট claim-এর কত ভাগ, আর ওই supplier-এর সবচেয়ে বেশি claim হওয়া component। সবচেয়ে বেশি claim হওয়া supplier হলুদ রঙে চিহ্নিত থাকে।
    • Components claimed most: কোন component, কোন supplier-এর কাছে, কয়টা unit।
    • R&I user অনুযায়ী টেবিল আর curve আগের মতোই আছে।
  • Download Excel: Admin Panel-এর Excel-এ চারটা নতুন শিট যোগ হয়েছে: QMS by control system, QMS by hardware (প্রতিটা model-এর project আর Lift ID সহ), Supplier claims, Components claimed most।

হিসাবের নিয়ম:

  • দ্বিতীয় Yes চাপার দিন থেকে supplier claim গোনা হয়। শুধু প্রথম Yes হয়েছে এমনগুলো আলাদা লাইনে দেখায়: "waiting for the second Yes"।
  • একটা AVR model-এ অনেকগুলো সারি থাকে, কিন্তু প্রতিটা lift একবারই গোনা হয়।
  • Delete করা lift কোনো হিসাবে আসে না।
