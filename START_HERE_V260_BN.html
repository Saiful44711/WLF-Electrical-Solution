Motor-first QMS, Controller Model ও Components CSV ইমপোর্ট: deployment নির্দেশিকা

কী বদলেছে

  • QMS Input নতুন ক্রম: Project information → Motor selection (Component Selection-এর মতো একই ইনপুট) → Control system ও serial → LOP/COP/Transom/cable → Other components। মোটর বাছলে দুটো কন্ট্রোলার (একটা MOT, একটা NICE3000+) ও একটা AVR সাজেস্ট হয়; ক্লিক করলে কন্ট্রোলার মডেল ও তার সব ডেটা বসে যায়, AVR "Other components"-এ যায়। SDB breaker rating Component data থেকে এসে Other components-এ আলাদা সারিতে থাকে।
  • Control system ও Controller model হাতে বাছার অপশন আগের মতোই আছে। কন্ট্রোলার বাছলে বড় টেবিল খোলে না; শুধু Encoder Card হাতে বাছতে হয়।
  • সব serial number বাধ্যতামূলক; আউটপুটে আলাদা SERIAL NUMBERS টেবিল। আউটপুট টেবিলে Price (৳)। MOTCUBE QMS-এ নেই।
  • Hardware Catalogue: কন্ট্রোলার মডেল ছোট থেকে বড়; ক্রম: Controller, COP, LOP, Transom, COP Faceplate, AVR, Others। COP Faceplate: Hairline, Silver Mirror, Golden Mirror, Black Mirror, Black Hairline, Rose Gold Mirror। MOTCUBE 5.5 / 7.5 / 11 kW-এর ফাঁকা টেবিল। "Value" এখন Price (BDT); Excel থেকে ২৭৪টা সারিতে দাম আছে।
  • Technical Support ফর্ম: Controller Brand বাছলে Controller Model বাধ্যতামূলক (MOT ৬, NICE3000+ ৭, MOTCUBE ৩)। Damage Demand ওই মডেল থেকে শুরু হয়।
  • Component Selection টেবিলে একক: Controller Power (kW), Controller Current (A), UPS (VA), ARD (A), Recommended AVR Rating (KVA), Main Power Cable Size (RM)।
  • Components Data: Download CSV ও Import CSV (শুধু Super Admin)। নমুনা ফাইল: Components-Data-SAMPLE-FORMAT.csv।
  • ⋮ মেনুর লাল ডট সরানো হয়েছে।
CSV ইমপোর্ট সব সারি মুছে নতুন সারি বসায়। আগে Download CSV দিয়ে বর্তমান ডেটার কপি রাখুন। Component change log-এ অনেক Deleted/Added লাইন দেখা যাবে।

৪. Components Data CSV ইমপোর্ট

  1. Super Admin → বাঁ মেনুর Components Data (Administration)।
  2. আগে Download CSV দিয়ে বর্তমান ডেটার কপি রাখুন।
  3. Import CSV → Components-Data-2026-11-20.csv (আপনার নতুন Excel থেকে বানানো, ৭৮ সারি) বেছে নিন।
  4. প্রিভিউ কার্ডে "78 rows are ready" দেখালে Replace all rows চাপুন। সমস্যা থাকলে কার্ডে সারি নম্বরসহ লেখা আসে এবং কিছুই বদলায় না।
  5. নিজের CSV বানাতে নমুনা ফাইলের হেডার হুবহু রাখুন (২৪ কলাম); প্রথম ৪ কলাম ফাঁকা রাখা যাবে না; ফাঁকা ঘর ফাঁকা রাখুন (Null লিখবেন না)।
CSV Excel-এ খুলে সেভ করলে Roping "2:1" সময় (২:০১) হয়ে যেতে পারে। Roping কলাম Text ফরম্যাট করে নিন, অথবা Notepad-এ এডিট করুন।

৫. যাচাই

  1. Ctrl+F5; ⋮ মেনুর নিচে WLF v2.6.0; লাল ডট নেই।
  2. Component Selection: কোনো মোটর বেছে দেখুন UPS (VA), ARD (A) ইত্যাদি।
  3. QMS Input: মোটর বাছুন → সাজেশন চিপ ক্লিক করুন → serial ভরে Save। QMS Data-তে ছয় টেবিল, SERIAL NUMBERS আলাদা।
  4. Technical Support → নতুন request: Controller Brand বাছলে Controller Model আসে।
  5. Hardware Catalogue: মডেল তালিকা ছোট থেকে বড়, MOTCUBE ও COP Faceplate দেখুন।

Excel-এর ডেটা নিয়ে যা লক্ষ করেছি

  • কিছু ঘরে Null ছিল; সেগুলো ফাঁকা করেছি।
  • Roping কলামে একটা ঘর সময় হিসেবে সেভ ছিল; "2:1" করেছি।
  • "Special Notes" সারি ইমপোর্ট করিনি; কয়েকটা সারি দেখতে ডুপ্লিকেটের মতো, যেমন আছে তেমনই রেখেছি।
  • MOTCUBE টেবিল MOT 5.5/7.5/11-এর কাঠামোর ফাঁকা কপি (শুধু group/hardware); আইটেম কোড, দাম আপনি ভরবেন।
  • সাজেশনের মিল (মোটরের পর কোন কন্ট্রোলার/AVR) Component data-র "Recommended" ঘর থেকে আসে; ক্যাটালগে মডেল নামে মিল না থাকলে চিপ আসে না।
