Google Drive backup · একবারের setup

আপনার Super Admin-এর নিয়ন্ত্রিত Google account-এর Drive-এ backup যাবে। App-এর “Backup” click থেকে upload হবে; laptop-এ কোনো background program লাগে না।

Client Secret ও Refresh Token শুধু Supabase server secrets-এ রাখবেন। GitHub, web/config.js, screenshot বা chat-এ দেবেন না। Actual credentials assistant-এর প্রয়োজন নেই।

A. নিজের Google Cloud project

  1. Google Cloud Console খুলে যে Google account-এর Drive-এ backup রাখবেন সেটি দিয়ে sign in করুন।
  2. Project selector → New project → নাম WLF Backup → Create → project select করুন।
  3. APIs & Services → Library → Google Drive API → Enable।
  4. Google Auth Platform / OAuth consent screen → Get started। App name WLF Backup, support email ও developer contact দিন।
  5. Personal Gmail হলে audience External। Data access-এ শুধু নিচের scope ব্যবহার করবেন: https://www.googleapis.com/auth/drive.file। Full Drive scope লাগবে না।
  6. নিজের production use-এর জন্য Audience → Publishing status → In production করুন। Testing mode-এ Drive scope-এর refresh token সাধারণত 7 দিনে expire হয়। Google কোনো required branding/domain/verification step চাইলে তাদের নির্দেশনা সম্পূর্ণ করুন; অনুমোদন bypass করবেন না।

B. OAuth client বানান

  1. Google Auth Platform → Clients → Create client। পুরোনো UI-তে APIs & Services → Credentials → Create credentials → OAuth client ID।
  2. Application type Web application; নাম WLF Backup Server।
  3. Authorized redirect URI-তে নিচের exact URL যোগ করুন:
https://developers.google.com/oauthplayground

Trailing slash যোগ করবেন না। Create করে Client ID ও Client Secret নিজের কাছে রাখুন। এটি Supabase Auth-এর Google login provider setup নয়।

C. একবার Google account authorize

  1. Google-এর official OAuth Playground খুলুন।
  2. উপরের gear / configuration খুলে Use your own OAuth credentials টিক দিন। নিজের Client ID এবং Client Secret দিন। Default Playground credentials ব্যবহার করলে refresh token 24 ঘণ্টায় revoked হতে পারে।
  3. OAuth flow Server-side, endpoints Google, access type Offline, prompt Consent Screen রাখুন।
  4. Step 1-এর Input your own scopes-এ শুধু নিচের scope দিন:
https://www.googleapis.com/auth/drive.file
  1. Authorize APIs → আপনার নির্ধারিত backup Google account select → permissions review করে Allow। Account ভুল হলে আবার সঠিক account দিয়ে করুন।
  2. Step 2 → Exchange authorization code for tokens। Refresh token copy করুন। Access token নয়। Refresh token না এলে নিজের client/offline/consent settings ঠিক করে authorization repeat করুন।
  3. Token তৈরি করার সময় app Testing থাকলে পরে Production করা মাত্র পুরোনো token ঠিক হবে ধরে নেবেন না; Production হওয়ার পরে আবার token নিন।

D. Supabase server secrets

  1. Supabase → Edge Functions → Secrets। তিনটি secret add করুন:
WLF_GOOGLE_CLIENT_ID       = নিজের OAuth Client ID
WLF_GOOGLE_CLIENT_SECRET   = নিজের OAuth Client Secret
WLF_GOOGLE_REFRESH_TOKEN   = নিজের Refresh Token
  1. Save করুন। Deployed wlf-maintenance নতুন secrets ব্যবহার করবে। প্রয়োজন হলে function redeploy করুন।
  2. App-এ Super Admin → Storage & Backup → Refresh usage। “Configured” দেখালে তিনটি env value আছে; actual token validity প্রথম upload-এ যাচাই হয়।
  3. Backup without Clear দিয়ে ছোট period test করুন। Drive-এ WLF Backups — আপনার project ref folder স্বয়ংক্রিয় তৈরি হবে। নিজে থেকে অন্য private folder share করার দরকার নেই।
  4. History → Parts/resume → Download part দিয়ে একটি independent copy রাখুন। শুরুতে clear করবেন না।

E. পরে কী মনে রাখবেন

  • এই permission app-created files-এ সীমিত; আপনার Drive-এর সব file পড়ার access চায় না।
  • Google account authorization revoke, token expiry বা Drive quota full হলে upload বন্ধ হবে; clear-এর আগে verified backup বাধ্যতামূলক।
  • Drive backup folder/file share করবেন না। Supabase service key ও Google refresh token package বা GitHub-এ upload করবেন না।
  • এটি click-triggered automatic save; daily scheduled backup এই version-এ নেই। App-এর backup চলাকালে page খোলা রাখুন।
  • OAuth connection চালু করতে Supabase Pro দরকার নেই; Google API ও Drive account-এর নিজস্ব quotas/policies প্রযোজ্য। নতুন paid Cloud services enable করার প্রয়োজন নেই।
