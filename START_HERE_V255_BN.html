কী বদলেছে

  • Supplier Claim মেনু থেকে demand খোলা: তালিকার DD নম্বরে (যেমন DD-7) ক্লিক করলে demand-এর বিস্তারিত খোলে, Pending আর Received দুই অবস্থাতেই। (এই পাতা থেকে "Receive demand" বোতাম আসে না, তাই Dispatch-এর Pending/Received অপরিবর্তিত থাকে।)
  • নতুন নাম: ঘর: Supplier Claimed / Supplier Confirmed। বোতাম: Claim Sent to Supplier, Supplier Accepted Claim। Super Admin-এর undo: Undo Claimed, Undo Confirmed।
  • Claim reference number (ঐচ্ছিক): "Supplier Accepted Claim" চাপলে একটা reference লেখার ঘর আসে (সর্বোচ্চ ৬০ অক্ষর, যেমন Arkel-এর ST…)। খালি রাখা যায়। মাল Received হওয়ার আগ পর্যন্ত Add/Edit reference দিয়ে পরে যোগ বা বদলানো যায়। দেখা যায় demand-এর বিস্তারিতে, Supplier Claim তালিকায় আর Excel-এর Supplier Claim Ref কলামে।
  • Undo Received (শুধু Super Admin): ভুল করে Received হয়ে গেলে Super Admin Pending-এ ফেরাতে পারেন; কে আর কখন করেছেন তা রেকর্ড হয়। Reference আগের মতোই থাকে। Received থাকা অবস্থায় Undo Confirmed/Undo Claimed চলে না, আগে Undo Received করতে হয়।
  • Light theme-এর ভুল ঠিক: কোনো lift parameter না বেছে Search করলে "Available motor options"-এর লেখা সাদা-জমিনে সাদা (অদৃশ্য) হচ্ছিল। কারণ: ফোন/পিসির সিস্টেম dark mode-এ থাকলে ব্রাউজার বোতামের ডিফল্ট লেখা সাদা করে দেয়, আর অ্যাপ Light থাকলে জমিন সাদাই থাকে। এখন লেখার রং স্পষ্ট করে দেওয়া হয়েছে।
  • নতুন controller MOTCUBE (Troubleshooting): MOT আর NICE3000+ এর পাশে। ভেতরে Error Solution: ৬১টা error code (H1 থেকে H62, শুধু H20 নেই — নিচের নোট দেখুন), প্রতিটায় English আর বাংলা। Code নম্বর বা লেখা দিয়ে খোঁজা যায় (H12, h12, 12, door lock)। কোডের পাতায় Permanent error ও Contact R&I team ট্যাগ আর Related parameters তালিকা।
  • Permanent Error Clearing: JSON-এর স্থায়ী error মোছার ধাপগুলো MOTCUBE-এর আলাদা sub option হিসেবে আছে (Super Admin edit/delete করতে পারেন)।
  • Super Admin সম্পাদনা: MOTCUBE-এ error code যোগ/বদল/মোছা, Bangla লেখা, Parameters, ট্যাগ, আর MOT/NICE3000+ এর মতো নতুন sub option (+ Add option)।
