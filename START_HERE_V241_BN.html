কী বদলেছে

  • Documents Links-এ ফোল্ডার: প্রতিটি sub menu-র (BOM, Diagram…) ভেতরে ফোল্ডার, আর ফোল্ডারের ভেতরেও ফোল্ডার (সর্বোচ্চ ৬ স্তর)। উপরে পথ দেখায় (যেমন Training › Manuals 2026), সাথে ← Up বোতাম।
  • Search: পুরো sub menu-র সব ফোল্ডার আর ডকুমেন্টের নামে খোঁজে, ফলাফলে 📁 দিয়ে ফোল্ডারের পথ দেখায়।
  • Add / Edit document: নতুন "Folder" ঘর আছে। যে ফোল্ডারে আছেন, সেটা আগে থেকেই বাছাই থাকে।
  • ফোল্ডারের নিয়ম: বানানো, Rename / move আর Delete করতে পারে শুধু Super Admin। শুধু খালি ফোল্ডার মোছা যায়।
  • R&I Project Manager → Add task: ঘরের নাম Assignee (সঠিক বানান)। নিজে থেকে কেউ বসে না। ড্রপডাউনে থাকে শুধু Project lead আর collaborator-রা, Name (ID) সহ। "Add user" দিয়ে নতুন কাউকে আনলে Save-এর সময় সে নিজে থেকেই collaborator হয়ে যায়। প্রজেক্টের বাইরের কাউকে সার্ভারও দিতে দেয় না।
  • v2.4.1: v2.4.0-এ ঘরের নাম ভুল করে "Assign user" করা হয়েছিল। "Assignee" ইংরেজিতে সঠিক বানান, তাই সেটাই ফেরানো হয়েছে। কাজের নিয়ম একই আছে। আগে v2.4.0-এর SQL চালিয়ে থাকলে নতুন UPDATE_V240.sql আবার চালান, এতে শুধু error বার্তার লেখা বদলাবে।
  • বানান: Installation ফর্মে "1. Asthetics" → "1. Aesthetics"। Troubleshooting-এ NICE3000+ Err38-এ "runs in in up direction" → "runs in up direction"।
  • ব্যাকআপ কিট: 01_STRUCTURE_BACKUP.sql চালালে Supabase সেই ভুল "RLS" সতর্কবার্তা আর দেখাবে না।

১. ব্যাকআপ (বাধ্যতামূলক)

  1. Supabase প্যাকেজের backup-kit ফোল্ডারের নতুন 01_STRUCTURE_BACKUP.sql আর 02_DATA_BACKUP.sql চালিয়ে দুটো CSV নিন। নাম দিন WLF-structure-…csv আর WLF-data-…csv।
  2. 03_RESTORE_TOOL.html-এ দুটো CSV দিয়ে দুবারই সবুজ "✓ ব্যাকআপ সম্পূর্ণ" দেখুন।
  3. GitHub থেকে Code → Download ZIP করে রাখুন (এখনকার v2.3.0)।

২. Supabase-এ ডাটাবেস আপডেট

  1. Supabase → আপনার প্রজেক্ট → SQL Editor → New query।
  2. UPDATE_V240.sql (v2.4.1 কপি) Notepad-এ খুলে Ctrl+A, Ctrl+C করুন, তারপর SQL Editor-এ পেস্ট করে Run চাপুন।
  3. "Potential issue detected / RLS" বার্তা এলে Run without RLS চাপুন। নতুন ফোল্ডার টেবিলের RLS এই SQL নিজেই চালু করে, তাই এখানে কোনো ঝুঁকি নেই।
  4. ফলাফলে পাঁচটা কলামই true হতে হবে:
    কলামমানে
    document_folders_readyফোল্ডারের টেবিল তৈরি হয়েছে
    document_folder_column_readyডকুমেন্টে ফোল্ডারের ঘর যোগ হয়েছে
    folders_protectedফোল্ডার টেবিলে RLS চালু (বাইরে থেকে লেখা যায় না)
    spelling_fixedদুটো বানান ঠিক হয়েছে
    task_and_folder_rules_readyAssignee আর ফোল্ডারের সার্ভার-নিয়ম চালু হয়েছে
পুরো SQL একটাই transaction-এ চলে। error হলে কিছুই বদলায় না, আর দুবার চালালেও কোনো ক্ষতি নেই।

৩. GitHub-এ ফাইল আপলোড

  1. WLF-GitHub-v2.4.1-UPLOAD.zip extract করুন, ভেতরের WLF-v2.4.1-upload ফোল্ডারে ঢুকুন। আগে v2.4.0 আপলোড করে থাকলেও এটাই দিন, একই ফাইল আবার গেলে কোনো ক্ষতি নেই।
  2. GitHub-এ repo খুলে Add file → Upload files চাপুন।
  3. ফোল্ডারের ভেতরের সব কিছু (Ctrl+A) টেনে আপলোড পেজে ছেড়ে দিন। একবারে ১০০টির কম ফাইল, তাই একবারেই হয়ে যাবে।
  4. Commit message দিন: v2.4.1 Document folders, Assignee, spelling। তারপর Commit directly to the main branch → Commit changes।
  5. Actions ট্যাবে সবুজ ✓ আসা পর্যন্ত অপেক্ষা করুন (২–১৫ মিনিট)।
ধাপ ২ (SQL) আগে, ধাপ ৩ (GitHub) পরে। SQL চালানোর আগে নতুন সাইট চালু হলে ফোল্ডারের বোতাম কাজ করবে না, তবে কোনো ডেটা নষ্ট হবে না।

৪. লাইভ সাইটে যাচাই

  1. Ctrl+F5 চাপুন, অথবা অ্যাপ বন্ধ করে আবার খুলুন। ⋮ মেনুর নিচে WLF v2.4.1 দেখাবে।
  2. Documents Links → একটা sub menu → + Add folder: ফোল্ডার বানান, ভেতরে + Add document দিন, তারপর উপরের পথে sub menu-র নামে ক্লিক করে ফিরে আসুন।
  3. Search-এ ডকুমেন্টের নাম লিখুন। ফলাফলে 📁 দিয়ে ফোল্ডারের পথ দেখাবে।
  4. R&I Project Manager → একটা প্রজেক্ট → Add task: Assignee খালি থাকবে, ড্রপডাউনে Project lead আর collaborator-রা থাকবে।
  5. Technical Support → Installation → + New request: Problem Sub-Category-তে "1. Aesthetics" দেখাবে।

ফোল্ডার ব্যবহারের নিয়ম

  • ফোল্ডার খোলা: 📁 নামে ক্লিক করুন। ফিরতে ← Up চাপুন, বা উপরের পথের যেকোনো নামে ক্লিক করুন।
  • ফোল্ডার সরানো বা নাম বদলানো: Rename / move চাপুন, তারপর "Inside" থেকে নতুন জায়গা বাছুন।
  • ডকুমেন্ট অন্য ফোল্ডারে সরানো: ডকুমেন্টের Edit → "Folder" বদলান → Save।
  • ফোল্ডার মোছা: আগে ভেতরের সব ডকুমেন্ট আর ফোল্ডার সরিয়ে বা মুছে খালি করুন। Drive-এর আসল ফাইল কখনো মোছে না।
  • আগের সব ডকুমেন্ট sub menu-র উপরের স্তরেই থাকবে। চাইলে Edit করে ফোল্ডারে সরাতে পারবেন।
